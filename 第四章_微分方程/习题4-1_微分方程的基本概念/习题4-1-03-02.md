# 习题 4-1 第 3(2) 题（由初值条件确定任意常数）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_一阶导·指数` $\to$ 算子:`一阶导·指数` $\to$ 根号:`R0` / 分式:`D0`

## 题目
确定函数 $y = (C_1 + x C_2)e^{2x}$ 中 $C_1, C_2$ 的值，使函数满足所给定的初值条件：$\left.y\right|_{x=0} = 0$，$\left.y'\right|_{x=0} = 1$。

## 答案与解析
**解**：
对 $y = (C_1 + x C_2)e^{2x}$ 求导，得：
$$y' = C_2 e^{2x} + 2(C_1 + x C_2)e^{2x} = [2C_1 + (2x + 1)C_2]e^{2x}$$
将初值条件 $\left.y\right|_{x=0} = 0$，$\left.y'\right|_{x=0} = 1$ 代入 $y$ 与 $y'$ 的表达式，得：
$$\begin{cases} 0 = (C_1 + 0\cdot C_2)e^0 = C_1 \\ 1 = (2C_1 + C_2)e^0 = C_2 \end{cases}$$
解得 $C_1 = 0$，$C_2 = 1$，在此初值条件下的特解为 $y = x e^{2x}$。
