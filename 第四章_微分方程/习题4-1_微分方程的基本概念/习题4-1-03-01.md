# 习题 4-1 第 3(1) 题（由初值条件确定任意常数）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_一阶导·三角` $\to$ 算子:`一阶导·三角` $\to$ 根号:`R0` / 分式:`D0`

## 题目
确定函数 $y = C_1\cos x + C_2\sin x$ 中 $C_1, C_2$ 的值，使函数满足所给定的初值条件：$\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 3$。

## 答案与解析
**解**：
对 $y = C_1\cos x + C_2\sin x$ 求导，得：
$$y' = -C_1\sin x + C_2\cos x$$
将初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 3$ 分别代入 $y$ 与 $y'$ 的表达式，得：
$$\begin{cases} 1 = C_1\cos 0 + C_2\sin 0 = C_1 \\ 3 = -C_1\sin 0 + C_2\cos 0 = C_2 \end{cases}$$
解得 $C_1 = 1$，$C_2 = 3$，对应特解为 $y = \cos x + 3\sin x$。
