# 习题 4-2 第 3(2) 题（一阶线性微分方程）

## 题目
求一阶线性微分方程 $y' = -2xy + 2x e^{-x^2}$ 的通解。

## 答案与解析
**解**：
原方程改写为标准形式 $y' + 2xy = 2x e^{-x^2}$，其中 $P(x) = 2x$，$Q(x) = 2x e^{-x^2}$。
由一阶线性微分方程通解公式得：
$$\begin{aligned}
y &= e^{-\int 2x \,dx} \left( \int 2x e^{-x^2} \cdot e^{\int 2x \,dx} \,dx + C \right) \\
&= e^{-x^2} \left( \int 2x e^{-x^2} \cdot e^{x^2} \,dx + C \right) = e^{-x^2} \left( \int 2x \,dx + C \right) \\
&= e^{-x^2}(x^2 + C)
\end{aligned}$$
