# 习题 4-2 第 4(3) 题（一阶微分方程初值问题）

## 题目
求微分方程 $(y + 3)dx + \cot x \,dy = 0$ 满足所给初值条件 $\left.y\right|_{x=0} = 1$ 的特解。

## 答案与解析
**解**：
分离变量得：
$$\tan x \,dx + \frac{dy}{y + 3} = 0$$
两边积分：
$$\int \tan x \,dx + \int \frac{dy}{y + 3} = 0 \implies -\ln|\cos x| + \ln|y + 3| = \ln|C|$$
故方程的通解为 $y + 3 = C\cos x$。
将初值条件 $\left.y\right|_{x=0} = 1$ 代入，得 $1 + 3 = C\cos 0 \implies C = 4$。
故所求特解为：
$$y = 4\cos x - 3$$
