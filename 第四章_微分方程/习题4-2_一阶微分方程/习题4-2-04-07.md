# 习题 4-2 第 4(7) 题（一阶齐次微分方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_一阶导` $\to$ 算子:`一阶导` $\to$ 根号:`R0` / 分式:`D1`

## 题目
求微分方程 $y' = \dfrac{x^2 + y^2}{xy}$ 满足所给初值条件 $\left.y\right|_{x=1} = 1$ 的特解。

## 答案与解析
**解**：
原方程可化为 $\dfrac{dy}{dx} = \dfrac{x}{y} + \dfrac{y}{x}$。
令 $u = \dfrac{y}{x}$，则 $\dfrac{dy}{dx} = u + x\dfrac{du}{dx}$，代入原方程得：
$$u + x\frac{du}{dx} = \frac{1}{u} + u \implies u \,du = \frac{dx}{x}$$
两边积分得 $\dfrac{1}{2}u^2 = \ln|x| + C$，将 $u = \dfrac{y}{x}$ 回代得通解：
$$\left(\frac{y}{x}\right)^2 = 2\ln|x| + 2C$$
将初值条件 $\left.y\right|_{x=1} = 1$ 代入，得 $1 = 0 + 2C \implies 2C = 1$。
故所求特解为：
$$\left(\frac{y}{x}\right)^2 = 2\ln|x| + 1 \quad (\text{或 } y^2 = x^2(2\ln x + 1))$$
