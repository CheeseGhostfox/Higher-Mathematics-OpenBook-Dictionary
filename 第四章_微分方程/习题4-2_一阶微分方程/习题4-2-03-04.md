# 习题 4-2 第 3(4) 题（一阶线性微分方程）

## 题目
求一阶线性微分方程 $y' + 2xy = 4x$ 的通解。

## 答案与解析
**解**：
这里 $P(x) = 2x$，$Q(x) = 4x$。由通解公式得：
$$\begin{aligned}
y &= e^{-\int 2x\,dx} \left( \int 4x \cdot e^{\int 2x\,dx} \,dx + C \right) \\
&= e^{-x^2} \left( \int 2e^{x^2} d(x^2) + C \right) = e^{-x^2}(2e^{x^2} + C) = C e^{-x^2} + 2
\end{aligned}$$
