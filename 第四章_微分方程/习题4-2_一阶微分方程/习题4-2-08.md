# 习题 4-2 第 *8 题（线性代换化可分离变量微分方程）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]

## 题目
求微分方程 $y' = \dfrac{1}{2}\tan^2(x + 2y)$ 的通解。

## 答案与解析
**解**：
令 $u = x + 2y$，则 $\dfrac{du}{dx} = 1 + 2\dfrac{dy}{dx}$，即 $\dfrac{dy}{dx} = \dfrac{1}{2}\left(\dfrac{du}{dx} - 1\right)$。
代入原方程得：
$$\frac{1}{2}\left(\frac{du}{dx} - 1\right) = \frac{1}{2}\tan^2 u \implies \frac{du}{dx} = 1 + \tan^2 u = \sec^2 u$$
分离变量得：
$$\cos^2 u \,du = \frac{1 + \cos 2u}{2} du = dx$$
两边积分得：
$$\frac{1}{2}u + \frac{1}{4}\sin 2u = x + C_1$$
将 $u = x + 2y$ 代回，得：
$$\frac{1}{2}(x + 2y) + \frac{1}{4}\sin(2x + 4y) = x + C_1$$
整理得所求通解为：
$$4y - 2x + \sin(2x + 4y) = C \quad \left(\text{或 } y = \frac{x}{2} - \frac{1}{4}\sin(2x + 4y) + C_1\right)$$
