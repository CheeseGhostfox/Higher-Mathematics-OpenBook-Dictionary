# 习题 4-2 第 3(3) 题（一阶线性微分方程）

## 题目
求一阶线性微分方程 $y' + y = e^{-x}$ 的通解。

## 答案与解析
**解**：
这里 $P(x) = 1$，$Q(x) = e^{-x}$。由通解公式得：
$$y = e^{-\int 1\,dx} \left( \int e^{-x} \cdot e^{\int 1\,dx} \,dx + C \right) = e^{-x} \left( \int 1\,dx + C \right) = e^{-x}(x + C)$$
