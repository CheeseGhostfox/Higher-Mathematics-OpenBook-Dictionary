# 习题 4-2 第 2(1) 题（一阶齐次微分方程）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]

## 题目
求齐次微分方程 $y^2 + x^2\dfrac{dy}{dx} = xy\dfrac{dy}{dx}$ 的通解。

## 答案与解析
**解**：
将原方程整理为：
$$\frac{dy}{dx} = \frac{y^2}{xy - x^2} = \frac{\left(\dfrac{y}{x}\right)^2}{\dfrac{y}{x} - 1}$$
令 $u = \dfrac{y}{x}$（即 $y = ux$），则 $\dfrac{dy}{dx} = u + x\dfrac{du}{dx}$，代入方程得：
$$u + x\frac{du}{dx} = \frac{u^2}{u - 1} \implies x\frac{du}{dx} = \frac{u}{u - 1}$$
分离变量得：
$$\frac{u - 1}{u} du = \frac{dx}{x}$$
两边积分：
$$\int \left(1 - \frac{1}{u}\right) du = \int \frac{dx}{x} \implies u - \ln|u| = \ln|x| + C$$
将 $u = \dfrac{y}{x}$ 回代，整理得原方程的通解为：
$$\frac{y}{x} = \ln|y| + C \quad (\text{或 } y = C e^{\frac{y}{x}})$$
