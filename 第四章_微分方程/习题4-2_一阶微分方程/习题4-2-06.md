# 习题 4-2 第 6 题（由切线斜率建立一阶线性方程求曲线）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W1_切线法线与曲率` $\to$ 算子:`代数曲线·切线与曲率` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求一曲线方程，该曲线过原点，并且它在点 $(x, y)$ 处的切线斜率等于 $2x + y$。

## 答案与解析
**解**：
设所求曲线方程为 $y = y(x)$，依题意有初值问题：
$$\frac{dy}{dx} - y = 2x, \quad \left.y\right|_{x=0} = 0$$
由一阶线性微分方程通解公式得：
$$y = e^{\int 1\,dx} \left( \int 2x e^{-\int 1\,dx} \,dx + C \right) = e^x \left( \int 2x e^{-x} \,dx + C \right) = C e^x - 2x - 2$$
由 $\left.y\right|_{x=0} = 0$ 得 $0 = C - 2 \implies C = 2$。
故所求曲线方程为：
$$y = 2e^x - 2x - 2$$
