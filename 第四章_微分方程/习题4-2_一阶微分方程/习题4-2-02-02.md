# 习题 4-2 第 2(2) 题（一阶齐次微分方程）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_一阶导` $\to$ 算子:`一阶导` $\to$ 根号:`R0` / 分式:`D1`

## 题目
求齐次微分方程 $\dfrac{dx}{x^2 - xy + y^2} = \dfrac{dy}{2y^2 - xy}$ 的通解。

## 答案与解析
**解**：
原方程可改写为：
$$\frac{dy}{dx} = \frac{2y^2 - xy}{x^2 - xy + y^2} = \frac{2\left(\dfrac{y}{x}\right)^2 - \dfrac{y}{x}}{1 - \dfrac{y}{x} + \left(\dfrac{y}{x}\right)^2}$$
令 $u = \dfrac{y}{x}$（即 $y = ux$），则 $\dfrac{dy}{dx} = u + x\dfrac{du}{dx}$，代入得：
$$u + x\frac{du}{dx} = \frac{2u^2 - u}{1 - u + u^2} \implies x\frac{du}{dx} = \frac{3u^2 - 2u - u^3}{1 - u + u^2} = -\frac{u(u - 1)(u - 2)}{1 - u + u^2}$$
分离变量并作部分分式分解：
$$\frac{u^2 - u + 1}{u(u - 1)(u - 2)} du = \left(\frac{1}{u - 1} - \frac{3}{2(u - 2)} - \frac{1}{2u}\right) du = \frac{dx}{x}$$
两边积分得：
$$\ln|u - 1| - \frac{3}{2}\ln|u - 2| - \frac{1}{2}\ln|u| = \ln|x| + \ln|C_1|$$
即 $\dfrac{u - 1}{\sqrt{|u|} \cdot |u - 2|^{\frac{3}{2}}} = C_1 x$。两边平方并代回 $u = \dfrac{y}{x}$，得通解为：
$$(y - x)^2 = C y(y - 2x)^3$$
