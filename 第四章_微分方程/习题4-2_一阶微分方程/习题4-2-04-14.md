# 习题 4-2 第 4(14) 题（一阶线性微分方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_一阶导·三角` $\to$ 算子:`一阶导·三角` $\to$ 根号:`R0` / 分式:`D1`

## 题目
求微分方程 $y' + y\cot x = 5e^{\cos x}$ 满足所给初值条件 $\left.y\right|_{x=\frac{\pi}{2}} = -4$ 的特解。

## 答案与解析
**解**：
这里 $P(x) = \cot x$，$Q(x) = 5e^{\cos x}$。由通解公式得：
$$\begin{aligned}
y &= e^{-\int \cot x\,dx} \left( \int 5e^{\cos x} \cdot e^{\int \cot x\,dx} \,dx + C \right) \\
&= \frac{1}{\sin x} \left( \int 5e^{\cos x} \sin x \,dx + C \right) = \frac{1}{\sin x} \left( -\int 5e^{\cos x} \,d(\cos x) + C \right) \\
&= \frac{-5e^{\cos x} + C}{\sin x}
\end{aligned}$$
将初值条件 $\left.y\right|_{x=\frac{\pi}{2}} = -4$ 代入，得 $-4 = -5e^0 + C \implies C = 1$。
故所求特解为：
$$y = \frac{1 - 5e^{\cos x}}{\sin x}$$
