# 习题 4-2 第 1(7) 题（可分离变量微分方程）

## 题目
求可分离变量微分方程 $\cos^2 x \dfrac{dy}{dx} + y = 0$ 的通解。

## 答案与解析
**解**：
原方程移项并分离变量，得：
$$\frac{dy}{y} = -\frac{dx}{\cos^2 x} = -\sec^2 x \,dx$$
等式两边积分：
$$\int \frac{dy}{y} = -\int \sec^2 x \,dx \implies \ln|y| = -\tan x + C_1$$
故原方程的通解为：
$$\ln|y| + \tan x = C \quad (\text{或 } y = C e^{-\tan x})$$
