# 习题 4-3 第 1(1) 题（可降阶二阶微分方程）

## 题目
求微分方程 $y'' = \dfrac{1}{1 + x^2}$ 的通解。

## 答案与解析
**解**：
方程两边对 $x$ 积分，得：
$$y' = \int \frac{1}{1 + x^2} \,dx = \arctan x + C_1$$
再次对 $x$ 积分（利用分部积分法），得：
$$\begin{aligned}
y &= \int (\arctan x + C_1) \,dx = x\arctan x - \int \frac{x}{1 + x^2} \,dx + C_1 x \\
&= x\arctan x - \frac{1}{2}\ln(1 + x^2) + C_1 x + C_2
\end{aligned}$$
