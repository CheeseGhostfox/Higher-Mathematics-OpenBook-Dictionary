# 习题 4-3 第 3 题（不显含 x 的二阶微分方程特解）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D1`

## 题目
求微分方程 $2y'' + \dfrac{1}{y^2} = 0$ 满足初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 1$ 的特解。

## 答案与解析
**解**：
方程不显含 $x$，令 $y' = p$，则 $y'' = p\dfrac{dp}{dy}$，方程化为：
$$2p\frac{dp}{dy} = -\frac{1}{y^2} \implies 2p \,dp = -\frac{1}{y^2} dy$$
两边积分得 $p^2 = \dfrac{1}{y} + C_1$。
由 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 1$ 得 $1 = 1 + C_1 \implies C_1 = 0$。
又由 $\left.y'\right|_{x=0} = 1 > 0$，得：
$$\frac{dy}{dx} = \frac{1}{\sqrt{y}} \implies \sqrt{y} \,dy = dx$$
两边积分得 $\dfrac{2}{3}y^{\frac{3}{2}} = x + C_2$。代入 $\left.y\right|_{x=0} = 1$ 得 $C_2 = \dfrac{2}{3}$。
故所求特解为：
$$\frac{2}{3}y^{\frac{3}{2}} = x + \frac{2}{3} \quad \left(\text{或 } y = \left(\frac{3}{2}x + 1\right)^{\frac{2}{3}}\right)$$
