# 习题 4-3 第 9(4) 题（二阶常系数非齐次线性微分方程）

## 题目
求微分方程 $y'' - 4y' + 4y = e^{-2x}$ 的通解。

## 答案与解析
**解**：
对应齐次方程的特征方程为 $r^2 - 4r + 4 = (r - 2)^2 = 0$，得 $r_1 = r_2 = 2$，齐次通解为：
$$Y = (C_1 + C_2 x)e^{2x}$$
因 $\lambda = -2$ 不是特征根，设特解为 $y^* = a e^{-2x}$，代入方程得 $(4 + 8 + 4)a e^{-2x} = e^{-2x} \implies a = \dfrac{1}{16}$。
故原方程的通解为：
$$y = (C_1 + C_2 x)e^{2x} + \frac{1}{16}e^{-2x}$$
