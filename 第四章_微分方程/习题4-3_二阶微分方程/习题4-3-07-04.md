# 习题 4-3 第 7(4) 题（二阶常系数齐次线性方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y'' + y' - 2y = 0$ 满足所给初值条件 $\left.y\right|_{x=0} = 0$，$\left.y'\right|_{x=0} = 3$ 的特解。

## 答案与解析
**解**：
所对应的特征方程为 $r^2 + r - 2 = (r - 1)(r + 2) = 0$，特征根为 $r_1 = -2$，$r_2 = 1$。
故微分方程的通解及其导数为：
$$y = C_1 e^{-2x} + C_2 e^x, \quad y' = -2C_1 e^{-2x} + C_2 e^x$$
由 $\left.y\right|_{x=0} = 0$，$\left.y'\right|_{x=0} = 3$ 得 $C_1 + C_2 = 0$，$-2C_1 + C_2 = 3$，解得 $C_1 = -1$，$C_2 = 1$。
故满足初值条件的特解为：
$$y = e^x - e^{-2x}$$
