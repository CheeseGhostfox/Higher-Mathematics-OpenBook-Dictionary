# 习题 4-3 第 8 题（由非齐次线性方程的三个特解还原方程与通解）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_一阶导·指数` $\to$ 算子:`一阶导·指数` $\to$ 根号:`R0` / 分式:`D0`

## 题目
已知 $y_1 = x e^x + e^{2x}$，$y_2 = x e^x - e^{-x}$，$y_3 = x e^x + e^{2x} - e^{-x}$ 是某二阶非齐次线性微分方程的 $3$ 个特解。
(1) 求此方程的通解；
(2) 写出此微分方程；
(3) 求此微分方程满足 $y(0) = 7$，$y'(0) = 6$ 的特解。

## 答案与解析
**解**：
(1) 由非齐次线性微分方程解的结构知：
$$\tilde{y}_1 = y_3 - y_2 = e^{2x}, \quad \tilde{y}_2 = y_1 - y_3 = e^{-x}$$
是对应齐次线性微分方程的两个线性无关的解；又 $y^* = y_3 - \tilde{y}_1 + \tilde{y}_2 = x e^x$（或取 $y_1 = x e^x + e^{2x}$）是非齐次线性微分方程的特解，故此方程的通解为：
$$y = C_1 e^{2x} + C_2 e^{-x} + x e^x \quad (C_1, C_2 \text{ 为任意常数})$$

(2) 因为对应齐次方程的特征根为 $r_1 = 2$，$r_2 = -1$，故特征方程为：
$$(r - 2)(r + 1) = r^2 - r - 2 = 0$$
即左端微分算子为 $y'' - y' - 2y$。将特解 $y^* = x e^x$（$(y^*)' = (x + 1)e^x$，$(y^*)'' = (x + 2)e^x$）代入左端得：
$$(x + 2)e^x - (x + 1)e^x - 2x e^x = (1 - 2x)e^x$$
故此微分方程为：
$$y'' - y' - 2y = e^x - 2x e^x$$

(3) 对通解 $y = C_1 e^{2x} + C_2 e^{-x} + x e^x$ 求导得：
$$y' = 2C_1 e^{2x} - C_2 e^{-x} + (x + 1)e^x$$
将初值条件 $y(0) = 7$，$y'(0) = 6$ 代入，得：
$$\begin{cases} C_1 + C_2 = 7 \\ 2C_1 - C_2 + 1 = 6 \end{cases} \implies C_1 = 4,\ C_2 = 3$$
故所求特解为：
$$y = 4e^{2x} + 3e^{-x} + x e^x$$
