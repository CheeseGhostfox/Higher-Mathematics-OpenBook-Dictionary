# 习题 4-3 第 7(8) 题（三阶常系数齐次线性方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_高阶导·二阶导` $\to$ 算子:`高阶导·二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y''' + 2y'' + y' = 0$ 满足所给初值条件 $\left.y\right|_{x=0} = 2$，$\left.y'\right|_{x=0} = 0$，$\left.y''\right|_{x=0} = -1$ 的特解。

## 答案与解析
**解**：
所对应的特征方程为 $r^3 + 2r^2 + r = r(r + 1)^2 = 0$，特征根为 $r_1 = r_2 = -1$，$r_3 = 0$。
故微分方程的通解及其一、二阶导数为：
$$y = C_1 + (C_2 + C_3 x)e^{-x}$$
$$y' = C_3 e^{-x} - (C_2 + C_3 x)e^{-x}, \quad y'' = -2C_3 e^{-x} + (C_2 + C_3 x)e^{-x}$$
代入 $\left.y\right|_{x=0} = 2$，$\left.y'\right|_{x=0} = 0$，$\left.y''\right|_{x=0} = -1$，得：
$$\begin{cases} C_1 + C_2 = 2 \\ C_3 - C_2 = 0 \\ -2C_3 + C_2 = -1 \end{cases} \implies C_1 = C_2 = C_3 = 1$$
故满足初值条件的特解为：
$$y = 1 + (1 + x)e^{-x}$$
