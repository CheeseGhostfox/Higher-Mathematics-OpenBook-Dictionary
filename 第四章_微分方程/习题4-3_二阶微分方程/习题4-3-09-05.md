# 习题 4-3 第 9(5) 题（二阶常系数非齐次线性微分方程）

## 题目
求微分方程 $y'' - y' = 7e^{-x}$ 的通解。

## 答案与解析
**解**：
对应齐次方程的特征方程为 $r^2 - r = 0$，得 $r_1 = 0$，$r_2 = 1$，齐次通解为：
$$Y = C_1 + C_2 e^x$$
因 $\lambda = -1$ 不是特征根，设特解为 $y^* = a e^{-x}$，代入原方程得 $2a e^{-x} = 7e^{-x} \implies a = \dfrac{7}{2}$。
故原方程的通解为：
$$y = C_1 + C_2 e^x + \frac{7}{2}e^{-x}$$
