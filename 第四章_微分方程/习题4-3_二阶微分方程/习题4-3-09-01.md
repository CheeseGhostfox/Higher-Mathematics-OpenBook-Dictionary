# 习题 4-3 第 9(1) 题（二阶常系数非齐次线性微分方程）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]

## 题目
求微分方程 $y'' + y' - 2y = 2e^x$ 的通解。

## 答案与解析
**解**：
对应齐次方程的特征方程为 $r^2 + r - 2 = (r - 1)(r + 2) = 0$，解得 $r_1 = 1$，$r_2 = -2$，故齐次通解为：
$$Y = C_1 e^x + C_2 e^{-2x}$$
自由项 $f(x) = 2e^x$ 中 $\lambda = 1$ 是特征方程的单根，设特解为 $y^* = a x e^x$，代入原方程得：
$$a(x + 2)e^x + a(x + 1)e^x - 2a x e^x = 3a e^x = 2e^x \implies a = \frac{2}{3}$$
故原方程的通解为：
$$y = C_1 e^x + C_2 e^{-2x} + \frac{2}{3}x e^x$$
