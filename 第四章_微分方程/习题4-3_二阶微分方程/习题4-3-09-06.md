# 习题 4-3 第 9(6) 题（二阶常系数非齐次线性微分方程）

## 题目
求微分方程 $y'' - y = e^{2x}$ 的通解。

## 答案与解析
**解**：
对应齐次方程的特征方程为 $r^2 - 1 = 0$，得 $r_1 = 1$，$r_2 = -1$，齐次通解为：
$$Y = C_1 e^x + C_2 e^{-x}$$
因 $\lambda = 2$ 不是特征根，设特解为 $y^* = a e^{2x}$，代入原方程得 $(4 - 1)a e^{2x} = e^{2x} \implies a = \dfrac{1}{3}$。
故原方程的通解为：
$$y = C_1 e^x + C_2 e^{-x} + \frac{1}{3}e^{2x}$$
