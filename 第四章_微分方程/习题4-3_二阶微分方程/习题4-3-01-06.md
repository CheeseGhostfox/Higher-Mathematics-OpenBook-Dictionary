# 习题 4-3 第 1(6) 题（不显含 y 的二阶微分方程）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y'' = y' + x$ 的通解。

## 答案与解析
**解**：
方程不显含 $y$，令 $y' = p$，则 $y'' = p'$，得一阶线性微分方程 $p' - p = x$。
由通解公式得：
$$p = e^{\int 1\,dx} \left( \int x e^{-\int 1\,dx} \,dx + C_1 \right) = e^x(-x e^{-x} - e^{-x} + C_1) = C_1 e^x - x - 1$$
即 $y' = C_1 e^x - x - 1$。两边对 $x$ 积分，得通解为：
$$y = C_1 e^x - \frac{1}{2}x^2 - x + C_2$$
