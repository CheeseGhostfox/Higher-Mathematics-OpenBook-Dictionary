# 习题 4-3 第 2(5) 题（不显含 x 的二阶微分方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `01_根式特区_1个根号(R1)` $\to$ 算子:`二阶导` $\to$ 根号:`R1` / 分式:`D0`

## 题目
求微分方程 $y'' = 3\sqrt{y}$ 满足初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 2$ 的特解。

## 答案与解析
**解**：
方程不显含 $x$，令 $y' = p$，则 $y'' = p\dfrac{dp}{dy}$，方程化为：
$$p\frac{dp}{dy} = 3y^{\frac{1}{2}} \implies p \,dp = 3y^{\frac{1}{2}} dy$$
两边积分得 $p^2 = 4y^{\frac{3}{2}} + C_1$。
代入初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 2$，得 $4 = 4 + C_1 \implies C_1 = 0$。
又由 $\left.y'\right|_{x=0} = 2 > 0$，取正根得：
$$\frac{dy}{dx} = 2y^{\frac{3}{4}} \implies y^{-\frac{3}{4}} dy = 2dx$$
两边积分得 $4y^{\frac{1}{4}} = 2x + C_2$。由 $\left.y\right|_{x=0} = 1$ 得 $C_2 = 4$，即 $y^{\frac{1}{4}} = \dfrac{x + 2}{2}$。
故所求特解为：
$$y = \frac{(x + 2)^4}{16}$$
