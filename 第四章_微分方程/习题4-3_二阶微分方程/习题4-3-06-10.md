# 习题 4-3 第 6(10) 题（四阶常系数齐次线性微分方程）

## 题目
求微分方程 $y^{(4)} - 2y'' + y = 0$ 的通解。

## 答案与解析
**解**：
所对应的特征方程为 $r^4 - 2r^2 + 1 = (r^2 - 1)^2 = 0$，得特征根 $r_1 = r_2 = 1$，$r_3 = r_4 = -1$。
故该微分方程的通解为：
$$y = (C_1 + C_2 x)e^x + (C_3 + C_4 x)e^{-x}$$
