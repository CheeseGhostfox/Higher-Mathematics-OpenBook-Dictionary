# 习题 4-3 第 1(2) 题（可降阶二阶微分方程）

## 题目
求微分方程 $y'' = x + \sin x$ 的通解。

## 答案与解析
**解**：
方程两边对 $x$ 积分，得：
$$y' = \int (x + \sin x) \,dx = \frac{1}{2}x^2 - \cos x + C_1$$
再次对 $x$ 积分，得通解为：
$$y = \int \left(\frac{1}{2}x^2 - \cos x + C_1\right) dx = \frac{1}{6}x^3 - \sin x + C_1 x + C_2$$
