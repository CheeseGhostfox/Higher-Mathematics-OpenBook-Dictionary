# 习题 4-3 第 1(8) 题（不显含 y 的二阶微分方程）

## 题目
求微分方程 $x^2 y'' + xy' = 1$ 的通解。

## 答案与解析
**解**：
方程不显含 $y$，令 $y' = p$，则 $y'' = p'$，方程化为 $x^2 p' + xp = 1$，即 $(xp)' = \dfrac{1}{x}$。
两边积分得：
$$xp = \ln|x| + C_1 \implies y' = p = \frac{\ln|x| + C_1}{x}$$
再次对 $x$ 积分，得原方程通解为：
$$y = \frac{1}{2}\ln^2|x| + C_1\ln|x| + C_2$$
