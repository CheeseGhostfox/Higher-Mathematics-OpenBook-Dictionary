# 习题 4-3 第 7(2) 题（二阶常系数齐次线性方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y'' + 25y = 0$ 满足所给初值条件 $\left.y\right|_{x=0} = 2$，$\left.y'\right|_{x=0} = 15$ 的特解。

## 答案与解析
**解**：
所对应的特征方程为 $r^2 + 25 = 0$，特征根为 $r_{1,2} = \pm 5i$。
故微分方程的通解及其导数为：
$$y = C_1\cos 5x + C_2\sin 5x, \quad y' = -5C_1\sin 5x + 5C_2\cos 5x$$
将初值条件 $\left.y\right|_{x=0} = 2$，$\left.y'\right|_{x=0} = 15$ 代入，得 $C_1 = 2$，$5C_2 = 15 \implies C_2 = 3$。
故满足初值条件的特解为：
$$y = 2\cos 5x + 3\sin 5x$$
