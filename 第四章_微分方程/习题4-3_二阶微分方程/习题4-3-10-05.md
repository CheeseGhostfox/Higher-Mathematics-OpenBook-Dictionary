# 习题 4-3 第 10(5) 题（二阶常系数非齐次线性方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y'' - y' = 2(1 - x)$ 满足所给初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 1$ 的特解。

## 答案与解析
**解**：
对应齐次方程特征根为 $r_1 = 0$，$r_2 = 1$，齐次通解为 $Y = C_1 + C_2 e^x$。
因 $\lambda = 0$ 是特征单根，设特解为 $y^* = x(ax + b)$，代入原方程得：
$$2a - (2ax + b) = -2ax + (2a - b) = 2 - 2x \implies a = 1,\ b = 0$$
故通解为：
$$y = C_1 + C_2 e^x + x^2, \quad y' = C_2 e^x + 2x$$
代入 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 1$，得 $C_1 + C_2 = 1$，$C_2 = 1 \implies C_1 = 0$，$C_2 = 1$。
故所求特解为：
$$y = e^x + x^2$$
