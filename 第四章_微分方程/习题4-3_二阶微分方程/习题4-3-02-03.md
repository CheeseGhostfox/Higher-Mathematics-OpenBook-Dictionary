# 习题 4-3 第 2(3) 题（不显含 x 的二阶微分方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y^3 y'' + 1 = 0$ 满足初值条件 $\left.y\right|_{x=1} = 1$，$\left.y'\right|_{x=1} = 0$ 的特解。

## 答案与解析
**解**：
方程不显含自变量 $x$，令 $y' = p$，则 $y'' = \dfrac{dp}{dx} = p\dfrac{dp}{dy}$，方程化为：
$$y^3 p \frac{dp}{dy} + 1 = 0 \implies p \,dp = -\frac{1}{y^3} dy$$
两边积分得 $p^2 = \dfrac{1}{y^2} + C_1$。
代入初值条件 $\left.y\right|_{x=1} = 1$，$\left.p\right|_{x=1} = 0$，解得 $C_1 = -1$，故：
$$p^2 = \frac{1 - y^2}{y^2} \implies \frac{dy}{dx} = \pm\frac{\sqrt{1 - y^2}}{y}$$
分离变量并积分得 $-\sqrt{1 - y^2} = \pm x + C_2$。由 $\left.y\right|_{x=1} = 1$ 得 $C_2 = \mp 1$，两边平方整理得：
$$1 - y^2 = (x - 1)^2 \implies y = \sqrt{2x - x^2}$$
