# 习题 4-3 第 10(6) 题（二阶常系数非齐次线性方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导·指数` $\to$ 算子:`二阶导·指数` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y'' - y = 4x e^x$ 满足所给初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 1$ 的特解。

## 答案与解析
**解**：
对应齐次方程特征根为 $r_1 = -1$，$r_2 = 1$，齐次通解为 $Y = C_1 e^{-x} + C_2 e^x$。
因 $\lambda = 1$ 是特征单根，设特解为 $y^* = x(ax + b)e^x$，代入原方程得：
$$(4ax + 2a + 2b)e^x = 4x e^x \implies a = 1,\ b = -1$$
故通解及其导数为：
$$y = C_1 e^{-x} + C_2 e^x + x(x - 1)e^x, \quad y' = -C_1 e^{-x} + C_2 e^x + (x^2 + x - 1)e^x$$
将 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 1$ 代入，得：
$$\begin{cases} C_1 + C_2 = 1 \\ -C_1 + C_2 - 1 = 1 \end{cases} \implies C_1 = -\frac{1}{2},\ C_2 = \frac{3}{2}$$
故所求特解为：
$$y = -\frac{1}{2}e^{-x} + \frac{3}{2}e^x + x(x - 1)e^x$$
