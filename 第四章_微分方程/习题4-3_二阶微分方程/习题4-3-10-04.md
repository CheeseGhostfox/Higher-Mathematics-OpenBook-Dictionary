# 习题 4-3 第 10(4) 题（二阶常系数非齐次线性方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导·三角` $\to$ 算子:`二阶导·三角` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y'' + y + \sin 2x = 0$ 满足所给初值条件 $\left.y\right|_{x=\pi} = 1$，$\left.y'\right|_{x=\pi} = 1$ 的特解。

## 答案与解析
**解**：
原方程即 $y'' + y = -\sin 2x$。对应齐次方程的特征根为 $r_{1,2} = \pm i$，齐次通解为 $Y = C_1\cos x + C_2\sin x$。
设特解为 $y^* = a\cos 2x + b\sin 2x$，代入原方程得 $-3a\cos 2x - 3b\sin 2x = -\sin 2x$，解得 $a = 0$，$b = \dfrac{1}{3}$。
故通解及其导数为：
$$y = C_1\cos x + C_2\sin x + \frac{1}{3}\sin 2x, \quad y' = -C_1\sin x + C_2\cos x + \frac{2}{3}\cos 2x$$
代入初值条件 $\left.y\right|_{x=\pi} = 1$，$\left.y'\right|_{x=\pi} = 1$，得：
$$-C_1 = 1, \quad -C_2 + \frac{2}{3} = 1 \implies C_1 = -1,\ C_2 = -\frac{1}{3}$$
故所求特解为：
$$y = -\cos x - \frac{1}{3}\sin x + \frac{1}{3}\sin 2x$$
