# 习题 4-3 第 2(1) 题（可降阶二阶微分方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D1`

## 题目
求微分方程 $y'' = (y')^{\frac{1}{2}}$ 满足初值条件 $\left.y\right|_{x=0} = 0$，$\left.y'\right|_{x=0} = 1$ 的特解。

## 答案与解析
**解**：
方程不显含 $y$，令 $y' = p$，则 $y'' = \dfrac{dp}{dx}$，得 $p^{-\frac{1}{2}} dp = dx$。
两边积分得 $2p^{\frac{1}{2}} = x + C_1$。代入初值条件 $\left.p\right|_{x=0} = \left.y'\right|_{x=0} = 1$，得 $C_1 = 2$。
故 $y' = p = \dfrac{(x + 2)^2}{4}$。
再次对 $x$ 积分得 $y = \dfrac{(x + 2)^3}{12} + C_2$。
代入初值条件 $\left.y\right|_{x=0} = 0$，得 $0 = \dfrac{8}{12} + C_2 \implies C_2 = -\dfrac{2}{3}$。
故所求特解为：
$$y = \frac{(x + 2)^3}{12} - \frac{2}{3}$$
