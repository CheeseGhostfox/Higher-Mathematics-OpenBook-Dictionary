# 习题 4-3 第 2(6) 题（不显含 x 的二阶微分方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $yy'' = 2\left[(y')^2 - y'\right]$ 满足初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 2$ 的特解。

## 答案与解析
**解**：
方程不显含 $x$，令 $y' = p$，则 $y'' = p\dfrac{dp}{dy}$，方程化为：
$$yp\frac{dp}{dy} = 2(p^2 - p) \implies \frac{dp}{p - 1} = \frac{2}{y} dy$$
两边积分得 $\ln|p - 1| = 2\ln|y| + \ln|C_1|$，即 $p - 1 = C_1 y^2$。
由 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 2$ 得 $2 - 1 = C_1 \implies C_1 = 1$，故：
$$y' = 1 + y^2 \implies \frac{dy}{1 + y^2} = dx$$
两边积分得 $\arctan y = x + C_2$。由 $\left.y\right|_{x=0} = 1$ 得 $C_2 = \dfrac{\pi}{4}$。
故所求特解为：
$$y = \tan\left(x + \frac{\pi}{4}\right)$$
