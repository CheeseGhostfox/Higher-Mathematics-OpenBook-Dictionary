# 习题 4-3 第 9(3) 题（二阶常系数非齐次线性微分方程）

## 题目
求微分方程 $y'' + 2y' + y = 5e^{-x}$ 的通解。

## 答案与解析
**解**：
对应齐次方程的特征方程为 $r^2 + 2r + 1 = (r + 1)^2 = 0$，得二重根 $r_1 = r_2 = -1$，齐次通解为：
$$Y = (C_1 + C_2 x)e^{-x}$$
因 $\lambda = -1$ 是二重特征根，设特解为 $y^* = a x^2 e^{-x}$，代入原方程得 $2a e^{-x} = 5e^{-x} \implies a = \dfrac{5}{2}$。
故原方程的通解为：
$$y = (C_1 + C_2 x)e^{-x} + \frac{5}{2}x^2 e^{-x}$$
