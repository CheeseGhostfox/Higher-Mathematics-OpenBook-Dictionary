# 习题 4-3 第 9(2) 题（二阶常系数非齐次线性微分方程）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $2y'' + 5y' = 5x^2 - 2x - 1$ 的通解。

## 答案与解析
**解**：
对应齐次方程的特征方程为 $2r^2 + 5r = 0$，解得 $r_1 = 0$，$r_2 = -\dfrac{5}{2}$，故齐次通解为：
$$Y = C_1 + C_2 e^{-\frac{5}{2}x}$$
自由项中 $\lambda = 0$ 是特征单根，设特解为 $y^* = x(ax^2 + bx + c) = ax^3 + bx^2 + cx$，代入原方程：
$$2(6ax + 2b) + 5(3ax^2 + 2bx + c) = 15ax^2 + (12a + 10b)x + (4b + 5c) = 5x^2 - 2x - 1$$
比较同次幂系数解得 $a = \dfrac{1}{3}$，$b = -\dfrac{3}{5}$，$c = \dfrac{7}{25}$。
故原方程的通解为：
$$y = C_1 + C_2 e^{-\frac{5}{2}x} + \frac{1}{3}x^3 - \frac{3}{5}x^2 + \frac{7}{25}x$$
