# 习题 4-3 第 1(5) 题（不显含 y 的二阶微分方程）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $(1 - x^2)y'' - xy' = 2$ 的通解。

## 答案与解析
**解**：
方程不显含未知函数 $y$，令 $y' = p$，则 $y'' = p'$，原方程化为一阶线性微分方程：
$$p' - \frac{x}{1 - x^2}p = \frac{2}{1 - x^2}$$
由一阶线性微分方程通解公式得：
$$\begin{aligned}
p &= e^{\int \frac{x}{1-x^2}dx} \left[ \int \frac{2}{1 - x^2} \cdot e^{-\int \frac{x}{1-x^2}dx} \,dx + C_1 \right] \\
&= \frac{1}{\sqrt{1 - x^2}} \left( \int \frac{2}{\sqrt{1 - x^2}} \,dx + C_1 \right) = \frac{2\arcsin x + C_1}{\sqrt{1 - x^2}}
\end{aligned}$$
即 $y' = \dfrac{2\arcsin x + C_1}{\sqrt{1 - x^2}}$。两边再对 $x$ 积分，得原方程通解为：
$$y = \int \frac{2\arcsin x + C_1}{\sqrt{1 - x^2}} \,dx = (\arcsin x)^2 + C_1\arcsin x + C_2$$
