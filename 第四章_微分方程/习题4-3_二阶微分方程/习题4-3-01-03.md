# 习题 4-3 第 1(3) 题（可降阶三阶微分方程）

## 题目
求微分方程 $y''' = x e^x$ 的通解。

## 答案与解析
**解**：
方程两边依次对 $x$ 积分三次（利用分部积分法 $\int x e^x dx = (x - 1)e^x$）：
第一次积分：
$$y'' = \int x e^x \,dx = x e^x - e^x + C_1'$$
第二次积分：
$$y' = \int (x e^x - e^x + C_1') \,dx = x e^x - 2e^x + C_1' x + C_2$$
第三次积分：
$$y = x e^x - 3e^x + \frac{1}{2}C_1' x^2 + C_2 x + C_3 = (x - 3)e^x + C_1 x^2 + C_2 x + C_3 \quad \left(\text{其中 } C_1 = \frac{1}{2}C_1'\right)$$
