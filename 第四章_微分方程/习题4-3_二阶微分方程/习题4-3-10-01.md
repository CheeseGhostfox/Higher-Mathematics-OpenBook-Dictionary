# 习题 4-3 第 10(1) 题（二阶常系数非齐次线性方程初值问题）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`AB_微积交叉与微分方程区` $\to$ `04_无根号算子区_二阶导` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
求微分方程 $y'' - 3y' + 2y = 5$ 满足所给初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 2$ 的特解。

## 答案与解析
**解**：
对应齐次方程的特征根为 $r_1 = 1$，$r_2 = 2$；自由项为常数 $5$，易求得特解 $y^* = \dfrac{5}{2}$，故通解为：
$$y = C_1 e^x + C_2 e^{2x} + \frac{5}{2}, \quad y' = C_1 e^x + 2C_2 e^{2x}$$
代入初值条件 $\left.y\right|_{x=0} = 1$，$\left.y'\right|_{x=0} = 2$，得：
$$\begin{cases} C_1 + C_2 + \dfrac{5}{2} = 1 \\ C_1 + 2C_2 = 2 \end{cases} \implies C_1 = -5,\ C_2 = \frac{7}{2}$$
故所求特解为：
$$y = -5e^x + \frac{7}{2}e^{2x} + \frac{5}{2}$$
