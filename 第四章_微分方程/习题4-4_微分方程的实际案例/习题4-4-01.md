# 习题 4-4 第 1 题（质点变力直线运动速率求解）

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第四章_习题索引|📂 第四章 微分方程索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W4_物理运动做功与水压力衰变` $\to$ 算子:`微分方程·物理动力建模` $\to$ 根号:`R0` / 分式:`D0`

## 题目
质量为 $1\,\text{g}$ 的质点受外力作用做直线运动，外力与时间成正比，与速率成反比。在 $t = 0\,\text{s}$ 时，速率为 $0\,\text{cm/s}$；$t = 10\,\text{s}$ 时，速率为 $50\,\text{cm/s}$，外力为 $4\,\text{g}\cdot\text{cm/s}^2$。从运动开始经过 $1\,\text{min}$ 后的速率是多少？

## 答案与解析
**解**：
设在时刻 $t$，质点运动速率为 $v(t)$。由牛顿第二定律及题意得：
$$f = m\frac{dv}{dt} = \frac{kt}{v}$$
代入已知条件 $m = 1$，$t = 10$，$v = 50$，$f = 4$，得比例系数 $k = \dfrac{f\cdot v}{t} = \dfrac{4 \times 50}{10} = 20$，从而微分方程为：
$$\frac{dv}{dt} = \frac{20t}{v}$$
分离变量并两边积分：
$$\int v \,dv = \int 20t \,dt \implies v^2 = 20t^2 + C$$
代入条件 $t = 10$，$v = 50$（注意题设在 $t = 10$ 时 $v = 50$，由此确定该运动阶段的积分常数 $C$），得 $2500 = 2000 + C \implies C = 500$，于是特解为：
$$v = \sqrt{20t^2 + 500}$$
当 $t = 60\,\text{s}$（即 $1\,\text{min}$）时，质点速率为：
$$v(60) = \sqrt{20 \times 60^2 + 500} = 50\sqrt{29} \approx 269.3\,(\text{cm/s})$$
