## 一、 极限变值题含参通式表

| 题型骨架（考卷把 $a, b, k$ 换成具体数字） | 一步到位直接得数 | 举例说明 |
| :--- | :--- | :--- |
| $\displaystyle\lim_{x\to 0}\frac{\sin(ax)}{\sin(bx)}$ 或 $\displaystyle\lim_{x\to 0}\frac{\tan(ax)}{\sin(bx)}$ | **$\dfrac{a}{b}$** | $\lim_{x\to 0}\frac{\sin 3x}{\tan 5x} = \frac{3}{5}$ |
| $\displaystyle\lim_{x\to 0}\frac{1 - \cos(ax)}{x^2}$ | **$\dfrac{a^2}{2}$** | $\lim_{x\to 0}\frac{1-\cos 4x}{x^2} = \frac{4^2}{2} = 8$ |
| $\displaystyle\lim_{x\to 0}\frac{\sqrt{1 + ax} - \sqrt{1 + bx}}{x}$ | **$\dfrac{a - b}{2}$** | $\lim_{x\to 0}\frac{\sqrt{1+2x}-\sqrt{1-3x}}{x} = \frac{2-(-3)}{2} = \frac{5}{2}$ |
| $\displaystyle\lim_{x\to 0}\frac{\sqrt[n]{1 + ax} - 1}{x}$ | **$\dfrac{a}{n}$** | $\lim_{x\to 0}\frac{\sqrt[3]{1+6x}-1}{x} = \frac{6}{3} = 2$ |
| $\displaystyle\lim_{x\to 0}(1 + ax)^{\frac{b}{x}}$ | **$e^{ab}$** | $\lim_{x\to 0}(1 - 2x)^{\frac{3}{x}} = e^{(-2)\times 3} = e^{-6}$ |
| $\displaystyle\lim_{x\to\infty}\left(\frac{x + a}{x + b}\right)^{kx + c}$ | **$e^{k(a - b)}$** | $\lim_{x\to\infty}\left(\frac{x+3}{x-1}\right)^{2x} = e^{2\times[3-(-1)]} = e^8$ |
| $\displaystyle\lim_{x\to\infty}\frac{a x^m + \text{低次项}}{b x^n + \text{低次项}}$ | $\begin{cases} \dfrac{a}{b}, & m = n \\ 0, & m < n \\ \infty, & m > n \end{cases}$ | 上下同次看最高次系数比；上低为 $0$；上高为 $\infty$ |
| $\displaystyle\lim_{x\to\infty}\left(\sqrt{x^2 + ax + b} - \sqrt{x^2 + cx + d}\right)$ | **$\dfrac{a - c}{2}\quad (x\to +\infty)$** | $\lim_{x\to+\infty}(\sqrt{x^2+4x}-\sqrt{x^2-2x}) = \frac{4-(-2)}{2} = 3$ |

## 二、 导数与 $n$ 阶导数含参通式表

| 函数 $y = f(x)$ | 一阶导数 $y'$ | $n$ 阶导数 $y^{(n)}$ 通式 |
| :--- | :--- | :--- |
| $y = e^{ax}$ | $a e^{ax}$ | **$a^n e^{ax}$** |
| $y = \sin(ax + b)$ | $a\cos(ax + b)$ | **$a^n \sin\left(ax + b + \dfrac{n\pi}{2}\right)$** |
| $y = \cos(ax + b)$ | $-a\sin(ax + b)$ | **$a^n \cos\left(ax + b + \dfrac{n\pi}{2}\right)$** |
| $y = \ln(ax + b)$ | $\dfrac{a}{ax + b}$ | **$(-1)^{n-1}\dfrac{(n-1)!\,a^n}{(ax + b)^n}$** |
| $y = \dfrac{1}{ax + b}$ | $-\dfrac{a}{(ax + b)^2}$ | **$(-1)^n\dfrac{n!\,a^n}{(ax + b)^{n+1}}$** |

## 三、 不定积分含参直接填坑表（考卷改常数 $a, b$ 直接代）

| 被积函数含参模型 | 一步到位原函数结果（别漏 $+ C$） | 填坑提示 |
| :--- | :--- | :--- |
| $\displaystyle\int \frac{1}{x^2 + a^2} \,dx$ | **$\dfrac{1}{a}\arctan\dfrac{x}{a} + C$** | 如分母是 $x^2+9$，则 $a=3$ |
| $\displaystyle\int \frac{1}{x^2 - a^2} \,dx$ | **$\dfrac{1}{2a}\ln\left|\dfrac{x - a}{x + a}\right| + C$** | 注意先减后加：$\frac{x-a}{x+a}$ |
| $\displaystyle\int \frac{1}{a^2 - x^2} \,dx$ | **$\dfrac{1}{2a}\ln\left|\dfrac{a + x}{a - x}\right| + C$** | 与上一行差一个负号 |
| $\displaystyle\int \frac{1}{\sqrt{a^2 - x^2}} \,dx$ | **$\arcsin\dfrac{x}{a} + C$** | 如 $\sqrt{4-x^2}$，则 $a=2$ |
| $\displaystyle\int \frac{1}{\sqrt{x^2 \pm a^2}} \,dx$ | **$\ln\left|x + \sqrt{x^2 \pm a^2}\right| + C$** | 根号照抄进对数里 |
| $\displaystyle\int \sqrt{a^2 - x^2} \,dx$ | **$\dfrac{x}{2}\sqrt{a^2 - x^2} + \dfrac{a^2}{2}\arcsin\dfrac{x}{a} + C$** | 定积分 $\int_0^a \sqrt{a^2-x^2}dx = \frac{\pi a^2}{4}$（$\frac{1}{4}$圆面积） |
| $\displaystyle\int x e^{ax} \,dx$ | **$\dfrac{ax - 1}{a^2}e^{ax} + C$** | 当 $a=1$ 时为 $(x-1)e^x+C$ |
| $\displaystyle\int x^2 e^{ax} \,dx$ | **$e^{ax}\left(\dfrac{x^2}{a} - \dfrac{2x}{a^2} + \dfrac{2}{a^3}\right) + C$** | 二次多项式乘指数通用秒杀式 |
| $\displaystyle\int e^{ax}\sin(bx) \,dx$ | **$\dfrac{e^{ax}\left[a\sin(bx) - b\cos(bx)\right]}{a^2 + b^2} + C$** | 无需循环分部积分两次，直接代 $a, b$！ |
| $\displaystyle\int e^{ax}\cos(bx) \,dx$ | **$\dfrac{e^{ax}\left[a\cos(bx) + b\sin(bx)\right]}{a^2 + b^2} + C$** | 无需循环分部积分两次，直接代 $a, b$！ |
| $\displaystyle\int x^n \ln x \,dx\ (n\neq -1)$ | **$\dfrac{x^{n+1}}{n+1}\left(\ln x - \dfrac{1}{n+1}\right) + C$** | 幂函数乘 $\ln x$ 直接代 $n$ |

## 四、 反常积分（广义积分）含参收敛与得数速查表

| 反常积分模型 | 收敛条件与直接得数 | 发散条件 |
| :--- | :--- | :--- |
| $\displaystyle\int_a^{+\infty} \frac{1}{x^p} \,dx\ (a > 0)$ | 当 **$p > 1$** 时收敛，值 $= \boldsymbol{\dfrac{a^{1-p}}{p - 1}}$（若 $a=1$ 则 $= \dfrac{1}{p-1}$） | 当 $p \le 1$ 时**发散**（$= +\infty$） |
| $\displaystyle\int_0^a \frac{1}{x^p} \,dx\ (a > 0)$ | 当 **$p < 1$** 时收敛，值 $= \boldsymbol{\dfrac{a^{1-p}}{1 - p}}$ | 当 $p \ge 1$ 时**发散**（$= +\infty$） |
| $\displaystyle\int_0^{+\infty} e^{-kx} \,dx$ | 当 **$k > 0$** 时收敛，值 $= \boldsymbol{\dfrac{1}{k}}$ | 当 $k \le 0$ 时**发散** |
| $\displaystyle\int_{-\infty}^{+\infty} \frac{1}{x^2 + a^2} \,dx\ (a > 0)$ | 恒收敛，值 $= \boldsymbol{\dfrac{\pi}{a}}$（若从 $0$ 到 $+\infty$ 则为 $\boldsymbol{\dfrac{\pi}{2a}}$） | — |
