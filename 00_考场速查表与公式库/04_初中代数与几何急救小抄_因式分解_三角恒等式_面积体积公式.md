## 一、 代数因式分解、求根公式与有理化配对表

1. **一元二次方程 $ax^2 + bx + c = 0$ 求根公式**：
   $$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}, \quad \text{韦达定理：} x_1 + x_2 = -\frac{b}{a},\ x_1 x_2 = \frac{c}{a}$$
2. **高频因式分解公式（求极限消零因子、有理函数拆项必用）**：
   - **平方差**：$a^2 - b^2 = (a - b)(a + b)$
   - **完全平方**：$(a \pm b)^2 = a^2 \pm 2ab + b^2$
   - **立方差**：$a^3 - b^3 = (a - b)(a^2 + ab + b^2)$（特别地：$x^3 - 1 = (x - 1)(x^2 + x + 1)$）
   - **立方和**：$a^3 + b^3 = (a + b)(a^2 - ab + b^2)$（特别地：$x^3 + 1 = (x + 1)(x^2 - x + 1)$）
3. **根式有理化（分子分母同乘“共轭搭档”去根号）**：
   - 见到 **$\sqrt{A} - \sqrt{B}$** $\implies$ 上下同乘 **$\sqrt{A} + \sqrt{B}$**，化为 $A - B$
   - 见到 **$\sqrt[3]{A} - \sqrt[3]{B}$** $\implies$ 上下同乘 **$\sqrt[3]{A^2} + \sqrt[3]{AB} + \sqrt[3]{B^2}$**，化为 $A - B$

## 二、 三角恒等式与降幂/和差化积全表

1. **三大平方关系（三角换元去根号的核心）**：
   $$\sin^2 x + \cos^2 x = 1, \quad 1 + \tan^2 x = \sec^2 x = \frac{1}{\cos^2 x}, \quad 1 + \cot^2 x = \csc^2 x = \frac{1}{\sin^2 x}$$
2. **二倍角公式与偶次幂“降幂积分公式”（积分遇到 $\sin^2 x, \cos^2 x$ 必用）**：
   $$\sin 2x = 2\sin x\cos x, \quad \cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$$
   $$\boldsymbol{\sin^2 x = \frac{1 - \cos 2x}{2}}, \quad \boldsymbol{\cos^2 x = \frac{1 + \cos 2x}{2}}, \quad \tan^2 x = \sec^2 x - 1$$
3. **积化和差公式（积分遇到 $\sin mx\cos nx$ 不同频相乘必用）**：
   $$\begin{aligned}
   \sin\alpha\cos\beta &= \frac{1}{2}[\sin(\alpha + \beta) + \sin(\alpha - \beta)] \\
   \cos\alpha\cos\beta &= \frac{1}{2}[\cos(\alpha + \beta) + \cos(\alpha - \beta)] \\
   \sin\alpha\sin\beta &= -\frac{1}{2}[\cos(\alpha + \beta) - \cos(\alpha - \beta)]
   \end{aligned}$$

## 三、 高数微元应用：平面图形面积、旋转体体积、弧长、曲率与物理公式

| 求解目标 | 标准计算公式 |
| :--- | :--- |
| **切线方程与法线方程**（在点 $(x_0, y_0)$ 处） | • **切线**：$y - y_0 = f'(x_0)(x - x_0)$<br>• **法线**：$y - y_0 = -\dfrac{1}{f'(x_0)}(x - x_0)$ |
| **曲率 $K$ 与曲率半径 $R$** | $K = \dfrac{\vert y''\vert}{\left[1 + (y')^2\right]^{\frac{3}{2}}}, \quad R = \dfrac{1}{K}$ |
| **直角坐标围成平面面积 $S$** | • 上下型：$S = \displaystyle\int_a^b \left[y_{\text{上}}(x) - y_{\text{下}}(x)\right] dx$<br>• 左右型：$S = \displaystyle\int_c^d \left[x_{\text{右}}(y) - x_{\text{左}}(y)\right] dy$ |
| **极坐标围成扇形面积 $S$** | $S = \dfrac{1}{2}\displaystyle\int_\alpha^\beta r^2(\theta) \,d\theta$ |
| **旋转体体积 $V$** | • **绕 $x$ 轴旋转**：$V_x = \pi\displaystyle\int_a^b y^2(x) \,dx$<br>• **绕 $y$ 轴旋转**（圆盘法/柱壳法）：$V_y = \pi\displaystyle\int_c^d x^2(y) \,dy = 2\pi\displaystyle\int_a^b x\,\vert y(x)\vert \,dx$ |
| **平面曲线弧长 $s$** | • 直角坐标：$s = \displaystyle\int_a^b \sqrt{1 + [y'(x)]^2} \,dx$<br>• 参数方程：$s = \displaystyle\int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2} \,dt$<br>• 极坐标：$s = \displaystyle\int_\alpha^\beta \sqrt{r^2(\theta) + [r'(\theta)]^2} \,d\theta$ |
| **常见几何体体积/表面积**（最值应用题常用） | • **圆柱**（底半径 $r$，高 $h$）：体积 $V = \pi r^2 h$，侧面积 $S_{\text{侧}} = 2\pi rh$，有盖表面积 $2\pi r^2 + 2\pi rh$<br>• **圆锥**（底半径 $r$，高 $h$）：体积 $V = \dfrac{1}{3}\pi r^2 h$<br>• **球体**（半径 $R$）：体积 $V = \dfrac{4}{3}\pi R^3$，表面积 $S = 4\pi R^2$<br>• **椭圆** $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$：面积 $S = \pi ab$ |
