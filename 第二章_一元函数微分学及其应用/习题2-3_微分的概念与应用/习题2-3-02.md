# 习题 2-3 第 2 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第二章_习题索引|📂 第二章 一元函数微分学及其应用索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W1_切线法线与曲率` $\to$ 算子:`代数曲线·切线与曲率` $\to$ 根号:`R0` / 分式:`D0`

## 题目
设曲线 $y = f(x)$ 在点 $x_0$ 处存在切线，试针对单调增凹（图A）、单调增凸（图B）、单调减凸（图C）、单调减凹（图D）四种情形（当 $\Delta x > 0$ 时），分别说明点 $x_0$ 处的 $dy$、$\Delta y$、$\Delta y - dy$ 的正负.

## 答案与解析
**解**：
由微分的几何意义（$\Delta y$ 为曲线纵坐标增量，$dy$ 为切线纵坐标增量）：
- **(A)** $dy > 0, \Delta y > 0, \Delta y - dy > 0$；
- **(B)** $dy > 0, \Delta y > 0, \Delta y - dy < 0$；
- **(C)** $dy < 0, \Delta y < 0, \Delta y - dy < 0$；
- **(D)** $dy < 0, \Delta y > 0, \Delta y - dy > 0$。
