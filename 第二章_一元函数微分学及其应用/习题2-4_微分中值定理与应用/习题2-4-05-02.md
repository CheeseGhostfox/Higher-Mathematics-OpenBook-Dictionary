# 习题 2-4 第 5(2) 题

## 题目
试用拉格朗日中值定理证明不等式：若 $a > b > 0, n > 1$，则 $nb^{n-1}(a-b) < a^n - b^n < na^{n-1}(a-b)$.

## 答案与解析
**证明**：
设函数 $f(x) = x^n$，其在闭区间 $[b, a]$ 上连续，在开区间 $(b, a)$ 内可导。由拉格朗日中值定理知，存在 $\xi \in (b, a)$，使：
$$f'(\xi) = n\xi^{n-1} = \frac{a^n - b^n}{a - b}$$
因为 $0 < b < \xi < a$ 且 $n > 1$，所以 $nb^{n-1} < n\xi^{n-1} < na^{n-1}$，两边同乘 $a - b > 0$ 得：
$$nb^{n-1}(a-b) < a^n - b^n < na^{n-1}(a-b)$$
