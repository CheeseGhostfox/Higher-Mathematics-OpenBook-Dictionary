# 习题 2-4 第 5(3) 题

## 题目
试用拉格朗日中值定理证明不等式：对任意正整数 $n$，有 $\frac{1}{n+1} < \ln\left(1+\frac{1}{n}\right) < \frac{1}{n}$.

## 答案与解析
**证明**：
设函数 $f(t) = \ln(1+t)$，对 $x > 0$，其在 $[0, x]$ 上连续，在 $(0, x)$ 内可导。由拉格朗日中值定理知，存在 $\xi \in (0, x)$，使：
$$f'(\xi) = \frac{1}{1+\xi} = \frac{\ln(1+x) - \ln 1}{x - 0} = \frac{\ln(1+x)}{x}$$
因为 $0 < \xi < x$，所以 $\frac{1}{1+x} < \frac{1}{1+\xi} < 1$，即 $\frac{x}{1+x} < \ln(1+x) < x$。
令 $x = \frac{1}{n}$，即得 $\frac{1}{n+1} < \ln\left(1+\frac{1}{n}\right) < \frac{1}{n}$。
