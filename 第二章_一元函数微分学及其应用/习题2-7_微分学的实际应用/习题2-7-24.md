# 习题 2-7 第 24 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第二章_习题索引|📂 第二章 一元函数微分学及其应用索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W1_切线法线与曲率` $\to$ 算子:`指数` $\to$ 根号:`R0` / 分式:`D0`

## 题目
若抛物线 $y = ax^2 + bx + c$ 在点 $x = 0$ 处与曲线 $y = e^x$ 相切且有相同的曲率半径，试确定系数 $a, b, c$.

## 答案与解析
**解**：
1. 两曲线在 $x = 0$ 处过同一点：$c = e^0 = 1$；
2. 两曲线在 $x = 0$ 处相切：$\left. (2ax+b) \right|_{x=0} = \left. e^x \right|_{x=0} \implies b = 1$；
3. 两曲线在 $x = 0$ 处有相同的曲率半径（即曲率相等）：
   $$\frac{|2a|}{(1+b^2)^{\frac{3}{2}}} = \frac{e^0}{(1+e^0)^{\frac{3}{2}}} \implies \frac{|2a|}{2\sqrt{2}} = \frac{1}{2\sqrt{2}} \implies a = \pm\frac{1}{2}$$
综上，$a = \pm\frac{1}{2}, b = 1, c = 1$。
