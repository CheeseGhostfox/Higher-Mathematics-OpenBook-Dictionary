# 习题 2-7 第 25 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第二章_习题索引|📂 第二章 一元函数微分学及其应用索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W1_切线法线与曲率` $\to$ 算子:`二阶导` $\to$ 根号:`R0` / 分式:`D0`

## 题目
设 $y = f(x)$ 为过原点的一条曲线，$f'(0), f''(0)$ 存在，有一条抛物线 $y = g(x)$ 与曲线 $y = f(x)$ 在原点相切，且在该点处有相同的曲率，在该点附近这两条曲线有相同的凹向，求 $g(x)$.

## 答案与解析
**解**：
设抛物线方程为 $g(x) = ax^2 + bx + c$。由题意知在原点处满足：
1. 过原点：$g(0) = f(0) = 0 \implies c = 0$；
2. 在原点相切：$g'(0) = f'(0) \implies b = f'(0)$；
3. 在原点处有相同的曲率且凹向相同：$g''(0) = f''(0) \implies 2a = f''(0) \implies a = \frac{1}{2}f''(0)$。

故所求抛物线为 $g(x) = \frac{1}{2}f''(0)x^2 + f'(0)x$。
