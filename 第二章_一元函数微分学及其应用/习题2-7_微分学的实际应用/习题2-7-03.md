# 习题 2-7 第 3 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第二章_习题索引|📂 第二章 一元函数微分学及其应用索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W3_最大最小与优化造价应用` $\to$ 算子:`整式多项式` $\to$ 根号:`R0` / 分式:`D0`

## 题目
已知铁路 $AB$ 长为 $100\text{ km}$，工厂 $C$ 距 $A$ 点的垂直距离为 $20\text{ km}$，现要在铁路线上选一点 $D$，向工厂修筑公路. 已知铁路与公路每千米费用之比为 $3:5$，为使货物从 $C$ 到 $B$ 的运费最省，求 $D$ 的位置.

## 答案与解析
**解**：
设 $AD = x$ ($0 \le x \le 100$)，则 $BD = 100 - x$，$CD = \sqrt{20^2 + x^2} = \sqrt{400 + x^2}$。
设铁路每千米运费为 $3k$，公路每千米运费为 $5k$（$k > 0$），则总运费目标函数为：
$$y(x) = 5k\sqrt{400+x^2} + 3k(100-x)$$
求导得：
$$y'(x) = k\left(\frac{5x}{\sqrt{400+x^2}} - 3\right)$$
令 $y'(x) = 0$，解得 $x = 15$。比较 $y(0) = 400k, y(15) = 380k, y(100) = 100\sqrt{26}k$，知当 $AD = 15\text{ km}$（即距 $A$ 点 $15\text{ km}$ 处）时，总运费最省。
