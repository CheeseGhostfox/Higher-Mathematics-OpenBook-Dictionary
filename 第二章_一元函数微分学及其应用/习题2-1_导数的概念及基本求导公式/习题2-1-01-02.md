# 习题 2-1 第 1(2) 题

## 题目
设 $f(x) = \begin{cases} x, & x < 0, \\ \ln(1+x), & x \ge 0, \end{cases}$ 则 $f(0) =$ ______，$f'(0) =$ ______.

## 答案与解析
**答案**：$0$，$1$

**解析**：
当 $x=0$ 时，$f(0) = \ln(1+0) = \ln 1 = 0$。
计算左、右导数：
$$f'_-(0) = \lim_{x \to 0^-} \frac{f(x) - f(0)}{x - 0} = \lim_{x \to 0^-} \frac{x - 0}{x - 0} = 1$$
$$f'_+(0) = \lim_{x \to 0^+} \frac{f(x) - f(0)}{x - 0} = \lim_{x \to 0^+} \frac{\ln(1+x) - 0}{x - 0} = 1$$
因为 $f'_-(0) = f'_+(0) = 1$，故 $f'(0) = 1$。
