# 习题 2-1 第 6(2) 题

## 题目
讨论函数 $y = \begin{cases} e^x + 1, & x \le 0, \\ x + 2, & x > 0 \end{cases}$ 在 $x=0$ 处的可导性.

## 答案与解析
**解**：
当 $x=0$ 时，$y(0) = e^0 + 1 = 2$。计算左、右导数：
$$y'_+(0) = \lim_{x \to 0^+} \frac{y(x) - y(0)}{x - 0} = \lim_{x \to 0^+} \frac{(x+2) - 2}{x - 0} = \lim_{x \to 0^+} \frac{x}{x} = 1$$
$$y'_-(0) = \lim_{x \to 0^-} \frac{y(x) - y(0)}{x - 0} = \lim_{x \to 0^-} \frac{e^x + 1 - 2}{x} = \lim_{x \to 0^-} \frac{e^x - 1}{x} = 1$$
由于函数在 $x=0$ 处的左、右导数相等，因此该函数在 $x=0$ 处可导，且 $y'(0) = 1$。
