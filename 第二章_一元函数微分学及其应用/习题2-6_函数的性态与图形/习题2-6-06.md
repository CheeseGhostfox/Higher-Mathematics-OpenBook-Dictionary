# 习题 2-6 第 6 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第二章_习题索引|📂 第二章 一元函数微分学及其应用索引]]
> 🔍 **考场速查坐标**：`A_纯微分与极限区` $\to$ `04_无根号算子区_三角` $\to$ 算子:`三角` $\to$ 根号:`R0` / 分式:`D1`

## 题目
试问：$a$ 为何值时，函数 $f(x) = a\sin x + \frac{1}{3}\sin 3x$ 在 $x = \frac{\pi}{3}$ 处取得极值？它是极小值还是极大值？

## 答案与解析
**解**：
求一阶导数 $f'(x) = a\cos x + \cos 3x$。由函数在 $x = \frac{\pi}{3}$ 处取得极值知：
$$f'\left(\frac{\pi}{3}\right) = a\cos\frac{\pi}{3} + \cos\pi = \frac{1}{2}a - 1 = 0 \implies a = 2$$
此时二阶导数为 $f''(x) = -2\sin x - 3\sin 3x$，代入 $x = \frac{\pi}{3}$ 得：
$$f''\left(\frac{\pi}{3}\right) = -2\sin\frac{\pi}{3} - 3\sin\pi = -\sqrt{3} < 0$$
由极值第二充分条件知，当 $a = 2$ 时，函数在 $x = \frac{\pi}{3}$ 处取得**极大值**，极大值为 $f\left(\frac{\pi}{3}\right) = \sqrt{3}$。
