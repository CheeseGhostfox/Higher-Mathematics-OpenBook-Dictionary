# 习题 2-6 第 2(3) 题

## 题目
证明不等式：当 $0 < x < \frac{\pi}{2}$ 时，$\sin x + \tan x > 2x$.

## 答案与解析
**证明**：
设 $f(x) = \sin x + \tan x - 2x$，在 $\left[0, \frac{\pi}{2}\right)$ 上连续，在 $\left(0, \frac{\pi}{2}\right)$ 内可导：
$$f'(x) = \cos x + \sec^2 x - 2 = (\sqrt{\cos x} - \sqrt{\sec x})^2 + \sec^2 x - \sec x > 0$$
（或求二阶导数 $f''(x) = -\sin x + 2\sec^2 x\tan x = \tan x(\sec^2 x - \cos x + \sec^2 x) > 0$，知 $f'(x) > f'(0) = 0$。）
故 $f(x)$ 在 $\left[0, \frac{\pi}{2}\right)$ 上单调增加，当 $0 < x < \frac{\pi}{2}$ 时 $f(x) > f(0) = 0$，即 $\sin x + \tan x > 2x$。
