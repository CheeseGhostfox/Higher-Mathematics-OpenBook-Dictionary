# 习题 2-6 第 12 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第二章_习题索引|📂 第二章 一元函数微分学及其应用索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W1_切线法线与曲率` $\to$ 算子:`代数曲线·切线与曲率` $\to$ 根号:`R0` / 分式:`D0`

## 题目
试决定曲线 $y = ax^3 + bx^2 + cx + d$ 中的 $a, b, c, d$，使曲线在 $x = -2$ 所对应的点处有水平切线，$(1, -10)$ 为曲线的拐点，且点 $(-2, 44)$ 在曲线上.

## 答案与解析
**解**：
由题设条件得方程组：
$$\begin{cases}
y(-2) = -8a + 4b - 2c + d = 44, \\
y'(-2) = 12a - 4b + c = 0, \\
y(1) = a + b + c + d = -10, \\
y''(1) = 6a + 2b = 0.
\end{cases}$$
解得：$a = 1, b = -3, c = -24, d = 16$。
