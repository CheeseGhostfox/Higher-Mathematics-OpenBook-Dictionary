# 习题 2-6 第 2(2) 题

## 题目
证明不等式：当 $0 < x < \frac{\pi}{2}$ 时，$\frac{2}{\pi}x < \sin x < x$.

## 答案与解析
**证明**：
1. 设 $f(x) = \sin x - x$，当 $x \in \left(0, \frac{\pi}{2}\right)$ 时，$f'(x) = \cos x - 1 < 0$，故 $f(x)$ 单调减少，$f(x) < f(0) = 0$，即 $\sin x < x$。
2. 设 $h(x) = \frac{\sin x}{x}$ ($x \in \left(0, \frac{\pi}{2}\right]$)，则 $h'(x) = \frac{x\cos x - \sin x}{x^2}$。
   记 $g(x) = x\cos x - \sin x$，在 $\left(0, \frac{\pi}{2}\right)$ 内 $g'(x) = -x\sin x < 0$，故 $g(x) < g(0) = 0$，从而 $h'(x) < 0$。
   因此 $h(x)$ 在 $\left(0, \frac{\pi}{2}\right]$ 上单调减少，有 $h(x) > h\left(\frac{\pi}{2}\right) = \frac{2}{\pi}$，即 $\sin x > \frac{2}{\pi}x$。
