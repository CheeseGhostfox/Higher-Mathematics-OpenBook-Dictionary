# 习题 2-2 第 18 题

## 题目
求参数曲线 $\begin{cases} x = \sqrt{2}\cos t, \\ y = \sin t \end{cases}$ 在 $t = \frac{\pi}{4}$ 处的切线方程和法线方程.

## 答案与解析
**解**：
切线与法线的斜率分别为：
$$k_1 = \left. \frac{dy}{dx} \right|_{t=\frac{\pi}{4}} = \left. \frac{\cos t}{-\sqrt{2}\sin t} \right|_{t=\frac{\pi}{4}} = -\frac{\sqrt{2}}{2}, \quad k_2 = -\frac{1}{k_1} = \sqrt{2}$$
当 $t = \frac{\pi}{4}$ 时，$x = 1, y = \frac{\sqrt{2}}{2}$。
故切线方程为 $y - \frac{\sqrt{2}}{2} = -\frac{\sqrt{2}}{2}(x - 1)$，即 $\sqrt{2}x + 2y - 2\sqrt{2} = 0$；
法线方程为 $y - \frac{\sqrt{2}}{2} = \sqrt{2}(x - 1)$，即 $2\sqrt{2}x - 2y - \sqrt{2} = 0$。
