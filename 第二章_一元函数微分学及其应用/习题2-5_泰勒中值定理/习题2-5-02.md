# 习题 2-5 第 2 题

## 题目
求函数 $f(x) = \frac{1}{x}$ 按 $x+1$ 的幂展开的带有拉格朗日型余项的 $n$ 阶泰勒公式.

## 答案与解析
**解**：
因为 $f^{(k)}(x) = \frac{(-1)^k k!}{x^{k+1}}$，所以在 $x_0 = -1$ 处有 $\frac{f^{(k)}(-1)}{k!} = -1$。
由泰勒公式知，$f(x) = \frac{1}{x}$ 按 $x+1$ 的幂展开的带有拉格朗日型余项的 $n$ 阶泰勒公式为：
$$f(x) = -1 - (x+1) - (x+1)^2 - \cdots - (x+1)^n + \frac{(-1)^{n+1}}{\xi^{n+2}}(x+1)^{n+1}$$
（其中 $\xi$ 介于 $-1$ 与 $x$ 之间。）
