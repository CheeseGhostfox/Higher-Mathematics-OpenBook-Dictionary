# 习题 2-5 第 3(1) 题

## 题目
利用带有佩亚诺型余项的麦克劳林公式求极限：$\lim_{x \to 0} \frac{\cos x - e^{-\frac{x^2}{2}}}{x^2[x + \ln(1-x)]}$.

## 答案与解析
**解**：
由麦克劳林公式：
$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} + o(x^4), \quad e^{-\frac{x^2}{2}} = 1 - \frac{x^2}{2} + \frac{x^4}{8} + o(x^4)$$
$$\ln(1-x) = -x - \frac{x^2}{2} + o(x^2)$$
代入原极限得：
$$\lim_{x \to 0} \frac{\cos x - e^{-\frac{x^2}{2}}}{x^2[x + \ln(1-x)]} = \lim_{x \to 0} \frac{\left(\frac{1}{24} - \frac{1}{8}\right)x^4 + o(x^4)}{-\frac{1}{2}x^4 + o(x^4)} = \lim_{x \to 0} \frac{-\frac{1}{12}x^4 + o(x^4)}{-\frac{1}{2}x^4 + o(x^4)} = \frac{1}{6}$$
