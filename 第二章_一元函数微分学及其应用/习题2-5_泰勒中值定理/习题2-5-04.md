# 习题 2-5 第 4 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第二章_习题索引|📂 第二章 一元函数微分学及其应用索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W7_概念判断与函数性质辨析` $\to$ 算子:`三角` $\to$ 根号:`R0` / 分式:`D0`

## 题目
试确定常数 $a$ 和 $b$，使 $f(x) = x - (a + b\cos x)\sin x$ 为当 $x \to 0$ 时关于 $x$ 的 $5$ 阶无穷小.

## 答案与解析
**解**：
利用麦克劳林公式 $\sin x = x - \frac{x^3}{6} + \frac{x^5}{120} + o(x^5)$，$\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} + o(x^4)$ 展开得：
$$f(x) = (1 - a - b)x + \left(\frac{a+b}{6} + \frac{b}{2}\right)x^3 - \left(\frac{a+b}{120} + \frac{b}{24} + \frac{b}{12}\right)x^5 + o(x^5)$$
要使 $f(x)$ 为当 $x \to 0$ 时关于 $x$ 的 $5$ 阶无穷小，需满足：
$$\begin{cases} 1 - a - b = 0, \\ \frac{a+b}{6} + \frac{b}{2} = 0, \end{cases} \implies a = \frac{4}{3}, \quad b = -\frac{1}{3}$$
（此时 $x^5$ 项系数为 $\frac{1}{30} \neq 0$，符合题意。）
