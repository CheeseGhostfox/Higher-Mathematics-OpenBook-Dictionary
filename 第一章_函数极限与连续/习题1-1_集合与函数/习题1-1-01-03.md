## 题目
设集合 $A = \{x \mid 3 < x < 5\}$, $B = \{x \mid x > 4\}$，试求 $A \cup B$, $A \cap B$, $A \setminus B$, $B \setminus A$.

## 答案与解析
**解**
- $A \cup B = \{x \mid x > 3\} = (3, +\infty)$
- $A \cap B = \{x \mid 4 < x < 5\} = (4, 5)$
- $A \setminus B = \{x \mid 3 < x \le 4\} = (3, 4]$
- $B \setminus A = \{x \mid x \ge 5\} = [5, +\infty)$
