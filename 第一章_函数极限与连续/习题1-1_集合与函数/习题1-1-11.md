# 习题 1-1 第 11 题

## 题目
设 $f\left(\frac{1-x}{x}\right) = \frac{1}{x} + \frac{x^2}{2x^2-2x+1} - 1 \quad (x \ne 0)$，求 $f(x)$.

## 答案与解析
**解**
**解法一（配凑法）**：
将等式右侧表示为 $\frac{1-x}{x}$ 的代数式：
$$f\left(\frac{1-x}{x}\right) = \left(\frac{1}{x}-1\right) + \frac{1}{\frac{2x^2-2x+1}{x^2}} = \frac{1-x}{x} + \frac{1}{2 - \frac{2}{x} + \frac{1}{x^2}}$$
注意到 $2 - \frac{2}{x} + \frac{1}{x^2} = 1 + \left(\frac{1-x}{x}\right)^2$。
故：
$$f\left(\frac{1-x}{x}\right) = \frac{1-x}{x} + \frac{1}{\left(\frac{1-x}{x}\right)^2 + 1}$$
将自变量整体替换为 $x$，得：
$$f(x) = x + \frac{1}{x^2+1}$$

**解法二（换元法）**：
令 $t = \frac{1-x}{x} \implies x = \frac{1}{1+t}$。代入原方程整理化简亦得 $f(x) = x + \frac{1}{x^2+1}$。
