# 习题 1-1 第 1 题 (4)

## 题目
设集合 $A = \{x \mid x^2 + x - 6 < 0\}$, $B = \{x \mid x^2 - 2x - 3 \le 0\}$，试求 $A \cup B$, $A \cap B$, $A \setminus B$, $B \setminus A$.

## 答案与解析
**解**
解不等式确定集合：
- 由 $x^2 + x - 6 < 0 \iff (x+3)(x-2) < 0$，得 $A = (-3, 2)$；
- 由 $x^2 - 2x - 3 \le 0 \iff (x-3)(x+1) \le 0$，得 $B = [-1, 3]$。

进行集合运算：
- $A \cup B = \{x \mid -3 < x \le 3\} = (-3, 3]$
- $A \cap B = \{x \mid -1 \le x < 2\} = [-1, 2)$
- $A \setminus B = \{x \mid -3 < x < -1\} = (-3, -1)$
- $B \setminus A = \{x \mid 2 \le x \le 3\} = [2, 3]$
