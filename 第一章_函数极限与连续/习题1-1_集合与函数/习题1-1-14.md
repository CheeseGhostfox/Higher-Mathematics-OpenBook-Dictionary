# 习题 1-1 第 14 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第一章_习题索引|📂 第一章 函数、极限与连续索引]]

## 题目
设 $f(x) = \begin{cases} 1+x, & x < 0 \\ e^x, & x \ge 0 \end{cases}$，求复合函数 $f[f(x)]$. 

## 答案与解析
**解**
外层展开：
$$f[f(x)] = \begin{cases} 1+f(x), & f(x) < 0 \\ e^{f(x)}, & f(x) \ge 0 \end{cases}$$
分类讨论内层自变量：
1. 当 $x < 0$ 时，$f(x) = 1+x$：
   - 若 $1+x < 0 \iff x < -1$，则 $f[f(x)] = 1 + (1+x) = 2+x$；
   - 若 $1+x \ge 0 \iff -1 \le x < 0$，则 $f[f(x)] = e^{1+x}$。
2. 当 $x \ge 0$ 时，$f(x) = e^x \ge 1 > 0$ 恒成立：
   - 故 $f[f(x)] = e^{e^x}$。

综上所述：
$$f[f(x)] = \begin{cases} 2+x, & x < -1 \\ e^{1+x}, & -1 \le x < 0 \\ e^{e^x}, & x \ge 0 \end{cases}$$
