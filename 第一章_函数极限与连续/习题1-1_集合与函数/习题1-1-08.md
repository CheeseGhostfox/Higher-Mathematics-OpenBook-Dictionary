## 题目
设 $f(x) = \sqrt{\sin x} + 2\cos^2 x$，求 $f\left(\frac{\pi}{2}\right), f\left(-\frac{\pi}{2}\right)$.

## 答案与解析
**解**
根式需满足 $\sin x \ge 0$，即定义域为 $2k\pi \le x \le (2k+1)\pi \ (k \in \mathbb{Z})$。
- $x = \frac{\pi}{2}$ 落在 $[0, \pi]$ 定义域内：
$$f\left(\frac{\pi}{2}\right) = \sqrt{\sin\frac{\pi}{2}} + 2\cos^2\frac{\pi}{2} = \sqrt{1} + 2 \times 0 = 1$$
- $x = -\frac{\pi}{2}$ 时，$\sin\left(-\frac{\pi}{2}\right) = -1 < 0$，无实数定义，故 $f\left(-\frac{\pi}{2}\right)$ 不存在。
