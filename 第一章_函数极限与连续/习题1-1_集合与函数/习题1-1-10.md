## 题目
设 $f(x) = \frac{1}{1-x} \quad (x \ne 0, x \ne 1)$，求 $f[f(x)]$ 和 $f\{f[f(x)]\}$.

## 答案与解析
**解**
1. 二重迭代：
$$f[f(x)] = \frac{1}{1 - \frac{1}{1-x}} = \frac{1-x}{(1-x)-1} = \frac{x-1}{x} \quad (x \ne 0, x \ne 1)$$

2. 三重迭代：
$$f\{f[f(x)]\} = f\left(\frac{x-1}{x}\right) = \frac{1}{1 - \frac{x-1}{x}} = \frac{1}{\frac{1}{x}} = x \quad (x \ne 0, x \ne 1)$$
