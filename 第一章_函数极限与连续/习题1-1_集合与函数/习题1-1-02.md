## 题目
设全集 $U = \{1, 2, 3, 4, 5, 6, 7\}$, $A = \{2, 3, 4\}$, $B = \{3, 6, 7\}$，求 $A^c, B^c, A^c \cap B^c, (A \cup B)^c$.

## 答案与解析
**解**
由余集定义可知：
- $A^c = U \setminus A = \{1, 5, 6, 7\}$
- $B^c = U \setminus B = \{1, 2, 4, 5\}$
- $A^c \cap B^c = \{1, 5\}$
- $(A \cup B)^c = U \setminus \{2, 3, 4, 6, 7\} = \{1, 5\}$
