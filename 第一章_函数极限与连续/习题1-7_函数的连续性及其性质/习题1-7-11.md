# 习题 1-7 第 11 题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第一章_习题索引|📂 第一章 函数、极限与连续索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W5_方程实根与零点存在证明` $\to$ 算子:`三角` $\to$ 根号:`R0` / 分式:`D0`

## 题目
证明：方程 $x - a\sin x - b = 0 \quad (a > 0, b > 0)$ 至少有一个不超过 $a+b$ 的正根.

## 答案与解析
**证明**
设辅助函数 $f(x) = x - a\sin x - b$。
$f(x)$ 在闭区间 $[0, a+b]$ 上是初等函数连续。
计算端点值：
- $f(0) = 0 - a\sin 0 - b = -b < 0$（因 $b > 0$）；
- $f(a+b) = (a+b) - a\sin(a+b) - b = a[1 - \sin(a+b)]$。
因为对任意实数 $\sin(a+b) \le 1$ 且 $a > 0$，所以 $f(a+b) \ge 0$。

分情况：
1. 若 $f(a+b) = 0$，则 $x = a+b > 0$ 就是满足条件的正根；
2. 若 $f(a+b) > 0$，则 $f(0) \cdot f(a+b) < 0$，由零点定理，在 $(0, a+b)$ 内至少存在一点 $\xi$，使得 $f(\xi) = 0$。

综上所述，方程至少存在一个正根，且该正根不超过 $a+b$。
