# 习题 1-7 第 3 题 (2)

## 题目
判断函数 $f(x) = \frac{x}{\tan x}$ 在点 $x = 0, x = \frac{\pi}{2}, x = \pi$ 处是否间断；说明类型并补充可去间断点定义.

## 答案与解析
**解**
- 在 $x = 0$ 处：$\lim_{x \to 0} \frac{x}{\tan x} = 1$ 存在有限，为**第一类可去间断点**。补充定义令 $f(0) = 1$ 即连续；
- 在 $x = \frac{\pi}{2}$ 处：$\tan\frac{\pi}{2} = \infty \implies \lim_{x \to \pi/2} \frac{x}{\tan x} = 0$，极限存在有限，为**第一类可去间断点**。补充定义令 $f\left(\frac{\pi}{2}\right) = 0$ 即连续；
- 在 $x = \pi$ 处：分母趋于 0 分子为 $\pi \ne 0 \implies \lim_{x \to \pi} f(x) = \infty$，为**第二类无穷间断点**。
