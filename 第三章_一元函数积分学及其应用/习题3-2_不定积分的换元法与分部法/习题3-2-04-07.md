## 题目
用分部积分法求不定积分 $\int x^2\cos x dx$。

## 答案与解析
**解**：
$$\begin{aligned}
\int x^2\cos x dx &= \int x^2 d(\sin x) = x^2\sin x - 2\int x\sin x dx \\
&= x^2\sin x + 2\int xd(\cos x) = x^2\sin x + 2x\cos x - 2\sin x + C
\end{aligned}$$
