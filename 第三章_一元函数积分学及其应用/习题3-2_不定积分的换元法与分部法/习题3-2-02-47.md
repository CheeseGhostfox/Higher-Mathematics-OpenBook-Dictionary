## 题目
用换元法求不定积分 $\int x\sqrt{x-3}dx$。

## 答案与解析
**解**：令 $t = \sqrt{x-3}$，则 $x = t^2 + 3$，$dx = 2tdt$，于是：
$$\begin{aligned}
\int x\sqrt{x-3}dx &= \int (t^2 + 3)t \cdot 2tdt = 2\int (t^4 + 3t^2)dt \\
&= \frac{2}{5}t^5 + 2t^3 + C = \frac{2}{5}(\sqrt{x-3})^5 + 2(\sqrt{x-3})^3 + C
\end{aligned}$$
