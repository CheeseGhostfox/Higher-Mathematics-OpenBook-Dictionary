## 题目
用换元法求不定积分 $\int \sqrt{1-2x}dx$。

## 答案与解析
**解**：令 $t = \sqrt{1-2x}$，则 $x = \frac{1-t^2}{2}$，$dx = -tdt$，故：
$$\int \sqrt{1-2x}dx = \int t(-tdt) = -\frac{1}{3}t^3 + C = -\frac{1}{3}(1-2x)^{\frac{3}{2}} + C$$
