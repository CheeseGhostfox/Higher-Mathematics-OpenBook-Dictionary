## 题目
求不定积分 $\int x\sqrt{x}dx$。

## 答案与解析
**解**：
$$\int x\sqrt{x}dx = \int x^{\frac{3}{2}}dx = \frac{x^{\frac{5}{2}}}{\frac{5}{2}} + C = \frac{2}{5}x^{\frac{5}{2}} + C = \frac{2}{5}x^2\sqrt{x} + C$$
