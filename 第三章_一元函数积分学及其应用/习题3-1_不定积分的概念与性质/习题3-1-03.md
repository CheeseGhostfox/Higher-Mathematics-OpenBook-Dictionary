## 题目
已知平面曲线 $y = f(x)$ 上任意一点 $M(x, y)$ 处的切线斜率为 $k = 4x^3 - 1$，且曲线经过点 $P(1, 3)$，求该曲线方程。

## 答案与解析
**解**：根据题意可得：
$$\frac{dy}{dx} = 4x^3 - 1$$
两边同时积分可得：
$$y = \int (4x^3 - 1)dx = x^4 - x + C$$
将点 $P(1, 3)$ 代入，得 $1 - 1 + C = 3 \implies C = 3$。
故所求曲线方程为 $y = x^4 - x + 3$。
