## 题目
一曲线通过点 $(e^2, 3)$，且在任意一点处的切线的斜率等于该点横坐标的倒数，求该曲线的方程。

## 答案与解析
**解**：由题意可得：
$$\frac{dy}{dx} = \frac{1}{x}$$
两边同时积分可得：
$$y = \ln|x| + C$$
代入点 $(e^2, 3)$，得 $\ln(e^2) + C = 3 \implies 2 + C = 3 \implies C = 1$。
所以该曲线方程为 $y = \ln x + 1$。
