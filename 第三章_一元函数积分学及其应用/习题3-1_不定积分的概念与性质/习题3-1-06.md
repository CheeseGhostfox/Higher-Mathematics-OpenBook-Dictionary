## 题目
已知 $f'(x) = 1 + x^2$，且 $f(0) = 1$，求 $f(x)$。

## 答案与解析
**解**：由题意可得：
$$f(x) = \int (1 + x^2)dx = x + \frac{1}{3}x^3 + C$$
代入 $f(0) = 1$，得 $C = 1$，所以 $f(x) = x + \frac{1}{3}x^3 + 1$。
