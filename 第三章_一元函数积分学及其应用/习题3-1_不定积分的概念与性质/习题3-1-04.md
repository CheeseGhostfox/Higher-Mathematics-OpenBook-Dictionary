## 题目
一曲线上任意一点 $(x, y)$ 处的切线斜率为 $\frac{1}{x} - \frac{1}{x^2}$，且 $x = 1$ 时，$y = 0$，求曲线 $y = f(x)$ 的方程。

## 答案与解析
**解**：根据题意可得：
$$\frac{dy}{dx} = \frac{1}{x} - \frac{1}{x^2}$$
两边同时积分可得：
$$y = \int \left(\frac{1}{x} - \frac{1}{x^2}\right)dx = \ln|x| + \frac{1}{x} + C$$
代入 $x = 1, y = 0$，得 $0 + 1 + C = 0 \implies C = -1$。
故所求曲线方程为 $y = \ln x + \frac{1}{x} - 1$。
