# 习题 3-1 第7题

## 题目
设函数 $F(x)$ 满足 $F'(x) = \frac{\cos 2x}{\sin^2 2x}$，$F\left(\frac{\pi}{4}\right) = -1$，求 $F(x)$。

## 答案与解析
**解**：根据题设条件，有：
$$\begin{aligned}
F(x) &= \int F'(x)dx = \int \frac{\cos 2x}{\sin^2 2x}dx = \int \frac{\cos^2 x - \sin^2 x}{4\sin^2 x \cdot \cos^2 x}dx \\
&= \frac{1}{4}\int \left(\frac{1}{\sin^2 x} - \frac{1}{\cos^2 x}\right)dx = -\frac{1}{4}(\tan x + \cot x) + C
\end{aligned}$$
由 $F\left(\frac{\pi}{4}\right) = -1$，得：
$$-\frac{1}{4}\left(\tan\frac{\pi}{4} + \cot\frac{\pi}{4}\right) + C = -1 \implies -\frac{1}{2} + C = -1 \implies C = -\frac{1}{2}$$
所以 $F(x) = -\frac{1}{4}(\tan x + \cot x) - \frac{1}{2}$。
