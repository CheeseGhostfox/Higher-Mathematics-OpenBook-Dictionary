## 题目
求不定积分 $\int (2x^3 - \sin x + 5\sqrt{x})dx$。

## 答案与解析
**解**：
$$\int (2x^3 - \sin x + 5\sqrt{x})dx = 2\int x^3 dx - \int \sin x dx + 5\int x^{\frac{1}{2}}dx = \frac{1}{2}x^4 + \cos x + \frac{10}{3}x^{\frac{3}{2}} + C$$
