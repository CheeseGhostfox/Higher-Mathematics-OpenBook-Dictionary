## 题目
求不定积分 $\int \frac{3x^4 + 3x^2 + 1}{x^2 + 1}dx$。

## 答案与解析
**解**：
$$\int \frac{3x^4 + 3x^2 + 1}{x^2 + 1}dx = \int \left(3x^2 + \frac{1}{1+x^2}\right)dx = x^3 + \arctan x + C$$
