# 习题 3-7 第*11题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第三章_习题索引|📂 第三章 一元函数积分学及其应用索引]]

## 题目
弹性体所受压缩之力 $F$ 与缩短距离 $x$ 之间关系按胡克定律 $F = kx$ 计算。现有一个弹簧，原长为 $1\text{ m}$，每压缩 $1\text{ cm}$ 需力 $5\text{ N}$，若自 $80\text{ cm}$ 压缩至 $60\text{ cm}$，则做了多少功？

## 答案与解析
**解**：以厘米为单位，劲度系数 $k = 5\text{ N/cm}$，弹簧长度从 $80\text{ cm}$ 压缩至 $60\text{ cm}$ 即缩短量从 $20\text{ cm}$ 增至 $40\text{ cm}$（或设端点的坐标 $x \in [60, 80]$，压缩力 $F = 5(100-x)\text{ N}$）：
$$W = \int_{60}^{80} 5(100 - x)dx = 3000\text{ N}\cdot\text{cm} = 30\text{ J}$$
（注：原书按厘米数值积分写作 $3000$。）
