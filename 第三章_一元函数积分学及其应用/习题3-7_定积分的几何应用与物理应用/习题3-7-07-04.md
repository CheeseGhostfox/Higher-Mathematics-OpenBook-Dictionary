## 题目
求曲线的弧长：曲线 $y = \ln\cos x$ 在 $0 \le x \le \frac{\pi}{4}$ 一段的弧。

## 答案与解析
**解**：因为 $y' = -\tan x$，故所求弧长为：
$$s = \int_0^{\frac{\pi}{4}} \sqrt{1 + \tan^2 x}dx = \int_0^{\frac{\pi}{4}} \sec x dx = \left[\ln|\sec x + \tan x|\right]_0^{\frac{\pi}{4}} = \ln(1 + \sqrt{2})$$
