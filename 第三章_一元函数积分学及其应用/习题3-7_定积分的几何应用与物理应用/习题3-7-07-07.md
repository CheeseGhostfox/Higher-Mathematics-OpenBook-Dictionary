## 题目
求曲线的弧长：阿基米德螺线 $r = a\theta$（$a > 0$）上相应于 $\theta$ 从 $0$ 到 $2\pi$ 的弧。

## 答案与解析
**解**：由极坐标弧长公式得：
$$s = \int_0^{2\pi} \sqrt{[r(\theta)]^2 + [r'(\theta)]^2}d\theta = a\int_0^{2\pi} \sqrt{1+\theta^2}d\theta = \frac{a}{2}\left[2\pi\sqrt{1+4\pi^2} + \ln\left(2\pi + \sqrt{1+4\pi^2}\right)\right]$$
