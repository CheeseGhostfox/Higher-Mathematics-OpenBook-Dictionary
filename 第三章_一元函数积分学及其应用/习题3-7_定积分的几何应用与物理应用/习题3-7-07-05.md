## 题目
求曲线的弧长：曲线 $x = \frac{1}{4}y^2 - \frac{1}{2}\ln y$ 在 $1 \le y \le e$ 一段的弧。

## 答案与解析
**解**：因为 $x'(y) = \frac{y}{2} - \frac{1}{2y}$，故 $1 + [x'(y)]^2 = \left(\frac{y}{2} + \frac{1}{2y}\right)^2$，所求弧长为：
$$s = \int_1^e \left(\frac{y}{2} + \frac{1}{2y}\right)dy = \left[\frac{1}{4}y^2 + \frac{1}{2}\ln y\right]_1^e = \frac{1}{4}(e^2 + 1)$$
