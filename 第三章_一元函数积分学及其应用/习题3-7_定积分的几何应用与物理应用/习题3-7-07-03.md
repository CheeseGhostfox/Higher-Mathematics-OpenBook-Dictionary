## 题目
求曲线的弧长：曲线 $y = x^{\frac{3}{2}}$ 在 $0 \le x \le 4$ 一段的弧。

## 答案与解析
**解**：因为 $y' = \frac{3}{2}\sqrt{x}$，故所求弧长为：
$$s = \int_0^4 \sqrt{1 + [y'(x)]^2}dx = \int_0^4 \sqrt{1 + \frac{9}{4}x}dx = \frac{8}{27}(10\sqrt{10} - 1)$$
