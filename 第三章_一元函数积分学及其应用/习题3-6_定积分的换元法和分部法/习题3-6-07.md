# 习题 3-6 第7题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第三章_习题索引|📂 第三章 一元函数积分学及其应用索引]]

## 题目
已知 $f(x)$ 满足方程 $f(x) = 3x - \sqrt{1-x^2}\int_0^1 f^2(x)dx$，求 $f(x)$。

## 答案与解析
**解**：设常数 $C = \int_0^1 f^2(x)dx$，则 $f(x) = 3x - C\sqrt{1-x^2}$。
两边平方并在 $[0, 1]$ 上积分：
$$C = \int_0^1 \left(3x - C\sqrt{1-x^2}\right)^2 dx = \int_0^1 \left[9x^2 - 6Cx\sqrt{1-x^2} + C^2(1-x^2)\right]dx = 3 - 2C + \frac{2}{3}C^2$$
整理得 $2C^2 - 9C + 9 = 0$，解得 $C = 3$ 或 $C = \frac{3}{2}$。
所以 $f(x) = 3x - 3\sqrt{1-x^2}$ 或 $f(x) = 3x - \frac{3}{2}\sqrt{1-x^2}$。
