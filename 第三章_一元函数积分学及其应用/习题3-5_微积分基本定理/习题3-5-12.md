## 题目
已知 $f'(x)\int_0^2 f(x)dx = 50$，且 $f(0) = 0$，试求 $f(x)$。

## 答案与解析
**解**：记定积分常数 $A = \int_0^2 f(x)dx \ne 0$，则 $f'(x) = \frac{50}{A}$。
积分并代入 $f(0) = 0$，得 $f(x) = \frac{50}{A}x$。
将其两边在 $[0, 2]$ 上积分：
$$A = \int_0^2 f(x)dx = \frac{50}{A}\int_0^2 x dx = \frac{100}{A} \implies A^2 = 100 \implies A = \pm 10$$
因此 $f(x) = \pm 5x$。
