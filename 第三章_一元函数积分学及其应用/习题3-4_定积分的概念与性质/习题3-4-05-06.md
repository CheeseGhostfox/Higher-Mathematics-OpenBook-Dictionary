## 题目
不计算积分，直接比较积分值的大小：$\int_0^\pi \sin x dx$ 与 $\int_0^\pi \cos x dx$。

## 答案与解析
**解**：在 $[0, \pi]$ 上 $\sin x \ge 0$（不恒为 $0$），故 $\int_0^\pi \sin x dx > 0$；而 $\cos x$ 在 $\left[0, \frac{\pi}{2}\right]$ 与 $\left[\frac{\pi}{2}, \pi\right]$ 上正负对称抵消，故 $\int_0^\pi \cos x dx = 0$。
所以：
$$\int_0^\pi \sin x dx > \int_0^\pi \cos x dx$$
