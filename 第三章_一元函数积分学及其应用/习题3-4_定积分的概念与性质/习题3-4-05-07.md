## 题目
不计算积分，直接比较积分值的大小：$\int_1^e \ln x dx$ 与 $\int_1^e \ln^2 x dx$。

## 答案与解析
**解**：在区间 $[1, e]$ 上 $0 \le \ln x \le 1$，故 $\ln x \ge \ln^2 x$（等号仅在端点 $x = 1, e$ 处成立），因此：
$$\int_1^e \ln x dx > \int_1^e \ln^2 x dx$$
