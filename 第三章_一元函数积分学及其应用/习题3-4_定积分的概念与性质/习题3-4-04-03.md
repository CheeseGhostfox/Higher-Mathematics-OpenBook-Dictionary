## 题目
试用定积分表示平面图形的面积：在区间 $[0, 2]$ 上，由抛物线 $y = x^2$（$0 \le x \le 1$）、直线 $y = x$（$1 \le x \le 2$）、直线 $x = 2$ 及 $x$ 轴所围成的阴影平面图形（图 3-10(3)）。

## 答案与解析
**解**：所求图形面积可表示为大三角形面积减去 $[0, 1]$ 上直线与抛物线之间的面积（或分段积分）：
$$S = \int_0^2 x dx - \int_0^1 (x - x^2)dx \quad \left(\text{或 } \int_0^1 x^2 dx + \int_1^2 x dx\right)$$
