# 习题 3-4 第*9题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第三章_习题索引|📂 第三章 一元函数积分学及其应用索引]]
> 🔍 **考场速查坐标**：`W_文字与场景应用特区` $\to$ `W2_所围面积与旋转体积及弧长` $\to$ 算子:`代数曲线·面积与体积微元` $\to$ 根号:`R0` / 分式:`D0`

## 题目
曲边梯形由曲线 $x = g(y) \ge 0$ 和直线 $y = c$，$y = d$（$c < d$）及 $y$ 轴围成，试用定积分定义导出其面积的定积分表示式。

## 答案与解析
**解**：
1. **分割**：在区间 $[c, d]$ 上任意插入 $n-1$ 个分点 $c = y_0 < y_1 < y_2 < \cdots < y_{i-1} < y_i < \cdots < y_n = d$，把 $[c, d]$ 分成 $n$ 个小区间 $[y_{i-1}, y_i]$，长度为 $\Delta y_i = y_i - y_{i-1}$。
2. **近似與求和**：在每个小区间 $[y_{i-1}, y_i]$ 上任取一点 $\xi_i$，以 $g(\xi_i)$ 为高、$\Delta y_i$ 为底的小矩形面积近似小曲边梯形面积 $\Delta S_i \approx g(\xi_i)\Delta y_i$，求和得：
$$S = \sum_{i=1}^n \Delta S_i \approx \sum_{i=1}^n g(\xi_i)\Delta y_i$$
3. **取极限**：令 $\lambda = \max_{1 \le i \le n}\{\Delta y_i\} \to 0$，取极限得曲边梯形面积的定积分表示式：
$$S = \lim_{\lambda \to 0} \sum_{i=1}^n g(\xi_i)\Delta y_i = \int_c^d g(y)dy$$
