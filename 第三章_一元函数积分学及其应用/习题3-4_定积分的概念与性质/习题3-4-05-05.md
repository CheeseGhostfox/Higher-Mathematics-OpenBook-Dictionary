## 题目
不计算积分，直接比较积分值的大小：$\int_{-\frac{\pi}{2}}^0 \sin x dx$ 与 $\int_0^{\frac{\pi}{2}} \sin x dx$。

## 答案与解析
**解**：在 $\left[-\frac{\pi}{2}, 0\right]$ 上 $\sin x \le 0$，故 $\int_{-\frac{\pi}{2}}^0 \sin x dx < 0$；在 $\left[0, \frac{\pi}{2}\right]$ 上 $\sin x \ge 0$，故 $\int_0^{\frac{\pi}{2}} \sin x dx > 0$。
因此：
$$\int_{-\frac{\pi}{2}}^0 \sin x dx < \int_0^{\frac{\pi}{2}} \sin x dx$$
