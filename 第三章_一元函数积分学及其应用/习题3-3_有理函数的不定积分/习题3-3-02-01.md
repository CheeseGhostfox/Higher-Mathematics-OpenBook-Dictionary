# 习题 3-3 第2(1)题

> 🔍 **考场速查坐标**：`B_纯积分计算区` $\to$ `04_无根号算子区_三角` $\to$ 算子:`三角` $\to$ 根号:`R0` / 分式:`D1`

## 题目
求三角函数有理式的不定积分 $\int \frac{1}{3+5\cos x}dx$。

## 答案与解析
**解**：令 $t = \tan\frac{x}{2}$，则 $\cos x = \frac{1-t^2}{1+t^2}$，$dx = \frac{2}{1+t^2}dt$，于是：
$$\begin{aligned}
\int \frac{1}{3+5\cos x}dx &= \int \frac{1}{3 + 5\frac{1-t^2}{1+t^2}} \cdot \frac{2}{1+t^2}dt = \int \frac{1}{4-t^2}dt \\
&= \frac{1}{4}\ln\left|\frac{2+t}{2-t}\right| + C = \frac{1}{4}\ln\left|\frac{2+\tan\frac{x}{2}}{2-\tan\frac{x}{2}}\right| + C
\end{aligned}$$
