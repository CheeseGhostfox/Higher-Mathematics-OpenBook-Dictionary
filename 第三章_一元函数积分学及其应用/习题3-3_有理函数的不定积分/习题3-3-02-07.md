## 题目
求三角函数有理式的不定积分 $\int \frac{1}{1+\sin x}dx$。

## 答案与解析
**解**：分子分母同乘 $(1-\sin x)$：
$$\int \frac{1}{1+\sin x}dx = \int \frac{1-\sin x}{\cos^2 x}dx = \int (\sec^2 x - \tan x\sec x)dx = \tan x - \sec x + C$$
