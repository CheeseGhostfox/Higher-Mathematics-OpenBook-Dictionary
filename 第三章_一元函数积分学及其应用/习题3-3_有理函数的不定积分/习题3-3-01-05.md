## 题目
求有理函数的不定积分 $\int \frac{x-2}{x^2+2x+3}dx$。

## 答案与解析
**解**：
$$\begin{aligned}
\int \frac{x-2}{x^2+2x+3}dx &= \frac{1}{2}\int \frac{2x+2}{x^2+2x+3}dx - \int \frac{3}{(x+1)^2+2}dx \\
&= \frac{1}{2}\ln(x^2+2x+3) - \frac{3\sqrt{2}}{2}\arctan\frac{x+1}{\sqrt{2}} + C
\end{aligned}$$
