## 题目
求无理函数的不定积分 $\int \frac{dx}{\sqrt{1+x-x^2}}$。

## 答案与解析
**解**：
$$\int \frac{dx}{\sqrt{1+x-x^2}} = \int \frac{d\left(x-\frac{1}{2}\right)}{\sqrt{\frac{5}{4} - \left(x-\frac{1}{2}\right)^2}} = \arcsin\frac{2x-1}{\sqrt{5}} + C$$
