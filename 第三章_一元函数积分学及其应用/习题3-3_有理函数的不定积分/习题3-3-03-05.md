# 习题 3-3 第3(5)题

## 题目
求无理函数的不定积分 $\int \frac{dx}{\sqrt[3]{(x-1)(x+1)^2}}$。

## 答案与解析
**解**：将被积式改写为 $\sqrt[3]{\frac{x+1}{x-1}} \cdot \frac{dx}{x+1}$。令 $t = \sqrt[3]{\frac{x+1}{x-1}}$，则 $x = \frac{t^3+1}{t^3-1}$，$dx = \frac{-6t^2 dt}{(t^3-1)^2}$，$\frac{1}{x+1} = \frac{t^3-1}{2t^3}$，于是：
$$\begin{aligned}
\int \frac{dx}{\sqrt[3]{(x-1)(x+1)^2}} &= -3\int \frac{dt}{t^3-1} = -\int \frac{dt}{t-1} + \int \frac{t+2}{t^2+t+1}dt \\
&= -\ln|t-1| + \frac{1}{2}\ln(t^2+t+1) + \sqrt{3}\arctan\frac{2t+1}{\sqrt{3}} + C
\end{aligned}$$
其中 $t = \sqrt[3]{\frac{x+1}{x-1}}$。
