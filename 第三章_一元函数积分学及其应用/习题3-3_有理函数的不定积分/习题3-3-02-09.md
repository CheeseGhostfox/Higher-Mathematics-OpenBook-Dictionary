## 题目
求三角函数有理式的不定积分 $\int \frac{\sin x}{\sin^2 x + 5\cos^2 x}dx$。

## 答案与解析
**解**：
$$\int \frac{\sin x}{\sin^2 x + 5\cos^2 x}dx = -\int \frac{d(\cos x)}{1 + 4\cos^2 x} = -\frac{1}{2}\arctan(2\cos x) + C$$
