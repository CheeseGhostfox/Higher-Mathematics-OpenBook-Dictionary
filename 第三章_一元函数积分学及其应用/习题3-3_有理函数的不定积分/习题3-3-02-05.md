## 题目
求三角函数有理式的不定积分 $\int \frac{\sin^5 x}{\cos^4 x}dx$。

## 答案与解析
**解**：令 $t = \cos x$，则：
$$\begin{aligned}
\int \frac{\sin^5 x}{\cos^4 x}dx &= -\int \frac{(1-t^2)^2}{t^4}dt = -\int \left(t^{-4} - 2t^{-2} + 1\right)dt \\
&= \frac{1}{3\cos^3 x} - \frac{2}{\cos x} - \cos x + C
\end{aligned}$$
