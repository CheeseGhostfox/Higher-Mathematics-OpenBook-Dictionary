## 题目
求无理函数的不定积分 $\int \frac{1}{\sqrt{x+1} + \sqrt[3]{x+1}}dx$。

## 答案与解析
**解**：令 $t^6 = x+1$，则 $dx = 6t^5 dt$，于是：
$$\begin{aligned}
\int \frac{1}{\sqrt{x+1} + \sqrt[3]{x+1}}dx &= \int \frac{6t^5 dt}{t^3 + t^2} = 6\int \frac{t^3+1-1}{t+1}dt \\
&= 2t^3 - 3t^2 + 6t - 6\ln|t+1| + C \\
&= 2\sqrt{x+1} - 3\sqrt[3]{x+1} + 6\sqrt[6]{x+1} - 6\ln\left(\sqrt[6]{x+1}+1\right) + C
\end{aligned}$$
