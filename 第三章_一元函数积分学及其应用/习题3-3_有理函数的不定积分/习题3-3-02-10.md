## 题目
求三角函数有理式的不定积分 $\int \frac{1+\tan x}{\sin 2x}dx$。

## 答案与解析
**解**：
$$\int \frac{1+\tan x}{\sin 2x}dx = \int \left(\frac{1}{\sin 2x} + \frac{1}{2\cos^2 x}\right)dx = \frac{1}{2}\ln|\csc 2x - \cot 2x| + \frac{1}{2}\tan x + C$$
