## 题目
求有理函数的不定积分 $\int \frac{x^2+x}{(x-2)^2}dx$。

## 答案与解析
**解**：将分子按 $(x-2)$ 展开：
$$\int \frac{x^2+x}{(x-2)^2}dx = \int \frac{(x-2)^2 + 5(x-2) + 6}{(x-2)^2}dx = \int \left[1 + \frac{5}{x-2} + \frac{6}{(x-2)^2}\right]dx = x + 5\ln|x-2| - \frac{6}{x-2} + C$$
