## 题目
求无理函数的不定积分 $\int \frac{\ln x}{x\sqrt{1+\ln x}}dx$。

## 答案与解析
**解**：
$$\begin{aligned}
\int \frac{\ln x}{x\sqrt{1+\ln x}}dx &= \int \frac{\ln x + 1 - 1}{\sqrt{1+\ln x}}d(1+\ln x) \\
&= \frac{2}{3}(1+\ln x)\sqrt{1+\ln x} - 2\sqrt{1+\ln x} + C \\
&= \frac{2}{3}(\ln x - 2)\sqrt{1+\ln x} + C
\end{aligned}$$
