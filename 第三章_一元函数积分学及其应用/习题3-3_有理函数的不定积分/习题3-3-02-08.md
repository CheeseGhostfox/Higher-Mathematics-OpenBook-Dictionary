# 习题 3-3 第2(8)题

> 🧭 **索引导航**：[[习题总索引|📚 习题总索引]] ｜ [[第三章_习题索引|📂 第三章 一元函数积分学及其应用索引]]
> 🔍 **考场速查坐标**：`B_纯积分计算区` $\to$ `04_无根号算子区_三角` $\to$ 算子:`三角` $\to$ 根号:`R0` / 分式:`D1`

## 题目
求三角函数有理式的不定积分 $\int \frac{1+\sin x}{1+\cos x}dx$。

## 答案与解析
**解**：利用半角公式 $1+\cos x = 2\cos^2\frac{x}{2}$，$\sin x = 2\sin\frac{x}{2}\cos\frac{x}{2}$：
$$\begin{aligned}
\int \frac{1+\sin x}{1+\cos x}dx &= \int \frac{1 + 2\sin\frac{x}{2}\cos\frac{x}{2}}{2\cos^2\frac{x}{2}}dx = \frac{1}{2}\int \sec^2\frac{x}{2}dx + \int \tan\frac{x}{2}dx \\
&= \tan\frac{x}{2} - 2\ln\left|\cos\frac{x}{2}\right| + C = \tan\frac{x}{2} + \ln\left(1 + \tan^2\frac{x}{2}\right) + C
\end{aligned}$$
