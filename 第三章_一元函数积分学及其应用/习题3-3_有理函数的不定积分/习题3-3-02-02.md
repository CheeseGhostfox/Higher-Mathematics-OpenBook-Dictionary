## 题目
求三角函数有理式的不定积分 $\int \cos^5 x dx$。

## 答案与解析
**解**：
$$\int \cos^5 x dx = \int (1 - \sin^2 x)^2 d(\sin x) = \sin x - \frac{2}{3}\sin^3 x + \frac{1}{5}\sin^5 x + C$$
