## 题目
求有理函数的不定积分 $\int \frac{1}{x^2-4}dx$。

## 答案与解析
**解**：
$$\int \frac{1}{x^2-4}dx = \frac{1}{4}\int \left(\frac{1}{x-2} - \frac{1}{x+2}\right)dx = \frac{1}{4}\ln\left|\frac{x-2}{x+2}\right| + C$$
