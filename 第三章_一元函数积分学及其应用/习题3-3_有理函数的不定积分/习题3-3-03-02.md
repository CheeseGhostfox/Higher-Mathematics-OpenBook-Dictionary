## 题目
求无理函数的不定积分 $\int \frac{dx}{\sqrt{(x-a)(b-x)}}$（$a \ne b$）。

## 答案与解析
**解**：不妨设 $a < b$，将根号内配方：
$$\int \frac{dx}{\sqrt{(x-a)(b-x)}} = \int \frac{dx}{\sqrt{\left(\frac{b-a}{2}\right)^2 - \left(x-\frac{a+b}{2}\right)^2}} = \arcsin\frac{2x-a-b}{b-a} + C$$
