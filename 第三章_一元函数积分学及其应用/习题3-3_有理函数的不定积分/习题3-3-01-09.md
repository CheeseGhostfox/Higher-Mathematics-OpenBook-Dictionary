## 题目
求有理函数的不定积分 $\int \frac{2x-5}{(x-1)^2(x+2)}dx$。

## 答案与解析
**解**：利用待定系数法分解部分分式：
$$\int \frac{2x-5}{(x-1)^2(x+2)}dx = \int \left[-\frac{1}{x+2} + \frac{1}{x-1} - \frac{1}{(x-1)^2}\right]dx = \ln\left|\frac{x-1}{x+2}\right| + \frac{1}{x-1} + C$$
