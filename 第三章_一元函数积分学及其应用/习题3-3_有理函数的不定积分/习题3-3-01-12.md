## 题目
求有理函数的不定积分 $\int \frac{x^4}{(1+x^2)^2}dx$。

## 答案与解析
**解**：
$$\begin{aligned}
\int \frac{x^4}{(1+x^2)^2}dx &= \int \frac{(x^2+1)(x^2-1)+1}{(1+x^2)^2}dx = \int \frac{x^2-1}{1+x^2}dx + \int \frac{1}{(1+x^2)^2}dx \\
&= x - 2\arctan x + \int \frac{1}{(1+x^2)^2}dx
\end{aligned}$$
对后一积分令 $x = \tan t$，得 $\int \frac{1}{(1+x^2)^2}dx = \int \cos^2 t dt = \frac{1}{2}t + \frac{1}{2}\sin t\cos t + C = \frac{1}{2}\arctan x + \frac{x}{2(1+x^2)} + C$。
故原式 $= x - \frac{3}{2}\arctan x + \frac{x}{2(1+x^2)} + C$。
